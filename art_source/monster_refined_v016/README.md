# Raker v016：下顎、抓咬與可動頸部

來源為 v015；中立高度 2.18 m、8,060 頂點／16,116 三角形不變。保留駝背、內收手掌、小幅抬頭與已烘焙污垢貼圖。新增下顎骨及深色口腔材質，匯出 46 節變形骨骼、3 材質、41 段 60 fps 原地動畫。

`monster_refined_v016.blend` 保留可編輯場景 `MONSTER_REFINED_V016`。`raker_refined_v016.glb` 已複製到正式 [raker.glb](../../assets/models/raker/raker.glb)。

同目錄 `grab_*.png` 是製作途中預覽，早於最終肩部權重與坐姿抬肘修正；最終外觀請以 Blender／正式 GLB 和遊戲測試場為準。

## 製作與重建

在 Blender 5.2.2 LTS 的現有 v015 來源檔執行 `author.py` 建立 v016 場景、下顎及動畫；再執行 `refine_skin.py` 平滑肩部權重並限制每頂點四個影響骨骼、加入口腔材質。`rebake.py` 僅重烘現有 v016 的抓咬動作，適用於後續調姿，不能代替首次建模。不要在已有 v016 場景時重複執行 `author.py`。

執行 `audit.py` 掃描全部 41 段的 2,121 個影格，再以 `finish.py` 匯出並保存。來源路徑設定在各腳本的 `OUT`；輸出依 NLA 軌道分段，僅選取角色網格與骨架、僅匯出變形骨骼。完成後複製 GLB 至正式資產目錄，執行 Godot 匯入與 Raker 測試。

## 動作規格

- 保留原 23 段動畫、既有片長及閉嘴姿勢；採 60 fps 烘焙以表達精確的抓咬時間。
- 站立／低姿態／坐姿各六段：伸手 0.6 秒、抓握循環 1 秒、咬擊 0.65 秒、放開 0.35 秒、掙脫／抓空各 0.45 秒。
- 咬擊最大張顎 38°，0.38 秒咬合。坐姿抬肩抬肘以避開椅背；肩部權重已修正，手腕沿前臂保持自然姿態。
- 頸部追視與接觸點修正由遊戲中的 SkeletonModifier3D 在动画求值後處理；來源檔保持原地固定 root。

最終 [穿插掃描](validation.json) 無非相鄰三角形交叉；排除共享頂點的面，不涵蓋所有運行時 IK、任意跨動畫混合及車輛翻滾。遊戲驗證與限制見 [v016 驗收](../../docs/validation/2026-09-22-raker-v016.md)。
