重建：在包含 v016 的 Blender 來源中執行 `refine_mouth.py`，再執行 `audit.py`、`finish.py`。腳本內 `OUT`／輸出路徑需對應工作目錄。不要在既有 v017 場景上重複建立；歷史 v016 檔保持不變。
