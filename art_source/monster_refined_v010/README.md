# 怪物模型細化 v010

2026-09-22，依使用者提供的灰白長臂怪物參考圖，在 Blender 5.2.2 LTS 製作。以 Raker v008 動畫模型為基礎；目前是獨立美術交付，尚未替換正式遊戲的 `assets/models/raker/raker.glb`。

## 交付

- [Blender 原檔](monster_refined_v010.blend)：目前场景 `MONSTER_REFINED_V010`，網格 `Refined010_Mesh`、骨架 `Refined010_Rig`。保留原始場景、v009 檢視場景及動畫。
- [可攜式 GLB](raker_refined_v010.glb)：只有新版模型與骨架，含 22 段動畫和內嵌 PNG；不含檢視用燈光、相機、地板。
- [1024 × 1024 膚色貼圖](raker_albedo_1k.png)：同時已打包進 Blender；使用原有 UV，骨架變形時貼圖跟隨表面。
- 實際 Blender 渲染：[正面](front.png)、[側面](side.png)、[背面](back.png)、[斜前方](threequarter.png)、[低姿態](crouch.png)、[頭部](head.png)。

## 本版修改

頭部略向前伸、收窄下臉、調整眼窩和眉骨；胸腹增加凹陷、肋骨與胸骨起伏；背部加強肩胛、上背體積與背脊溝。保留長臂比例，微調手背與前臂肌腱表面，指端改為較深的乾燥角質色。增加灰白斑駁膚色，保留低面數外觀。

只細分胸腹、頸部與頭部需要細節的位置。初版全身細分造成抬臂時的肩部穿插，已改為保留關節區域原網格並重新通過全部動畫掃描。沒有修改原始共享動畫 actions。

## 本次驗證

[數據](validation.json)：中立網格高 2.180000067 m、2,530 頂點、5,056 三角面、45 根變形骨；0 非流形邊、0 零面積面、0 未綁定頂點，最大權重總和誤差 4.48e-8。

22 段動畫共 729 個烘焙影格：0 非相鄰三角形穿插。低姿態片段最高約 1.527 m，仍小於 1.60 m 低姿態膠囊。穿插檢查排除共用頂點的三角形，未窮舉動畫混合。攀爬、翻越的模型原點相對腳底可以出現負高度，與原 v008 動畫語義相同。

Godot 4.7.2 使用 GLTFDocument 直接載入本版 GLB：身高、45 骨、22 動畫、兩個材質表面的貼圖與 UV 全部 PASS。日誌位於 `.godot/refined-v010-import.log`。這是新版資產載入驗證；本次沒有重新執行遊戲戰鬥／車內行為回歸，也沒有操作遊戲視窗。

## 重建

使用包含 Raker v008 與 v009 檢視場景的來源副本，依序在 Blender 執行 [refine.py](refine.py)、[audit.py](audit.py)、[finish.py](finish.py)。腳本輸出路徑位於頂端。`refine.py` 只重建自身的 v010 場景；重建會清除該場景的手動編輯，先保存副本。`finish.py` 烘焙貼圖、輸出 GLB 並渲染多角度檢視。修改後應重新生成 `validation.json`。

本版採膚色貼圖與固定粗糙度，尚無獨立法線貼圖、地形腳掌 IK 或逐指抓點 IK。
