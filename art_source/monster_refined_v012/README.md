| 三角面 | 5,928 | 16,116 |

對頭部、頸部與軀幹細分，並實際平滑頂點位置，修順胸背與頭部輪廓；全身使用平滑法線。深眼窩與嘴部使用較低平滑幅度保留凹陷。肩膀、髖部與四肢關節的原變形區保持既有拓撲，避免將面數平均浪費在所有位置。頭頂以局部修正維持 2.18 m，骨架與碰撞尺寸不縮放。

保留 v011 的 UV、膚色貼圖與 22 段動作；新增頂點沿面插值 UV／骨權重。嘴巴仍隨頭骨運動，沒有新增獨立張嘴動畫。

[Blender 檢查數據](validation.json)：0 非流形邊、0 零面積面、0 未綁定頂點；729 個影格零非相鄰三角形穿插。低姿態最高約 1.501 m。未窮舉跨動畫混合，也未測大量同屏怪物的 GPU 效能。

## 重建

開啟含 v011 場景的來源檔，依序執行 [refine.py](refine.py)、[audit.py](audit.py)、[finish.py](finish.py)。refine 只重建自身 v012 場景，手動編輯請先另存副本。finish 沿用已打包的 v011 貼圖，不重新烘焙或修改舊版材質。輸出路徑在檔案頂端。

遊戲接入與本次回歸結果見[驗證紀錄](../../docs/validation/2026-09-22-raker-v012.md)。
