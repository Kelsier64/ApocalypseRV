# <名稱> — image-to-3D 建模 request

先建立 `requests/<名稱>/` 資料夾，再將本模板複製到 `requests/<名稱>/<名稱>.md`。這份 request 供使用者後續製作參考圖，再透過 image-to-3D diffuser 生成模型；寫 request 時不必同時生成圖片。無關項目省略，未確認事項直接註明。已有參考圖時，存放在此資料夾並在 request 中連結。路徑以專案根目錄為基準。

- **要做什麼**：物件用途與需要製作的部分。
- **替換位置與尺寸方向**：場景／外觀節點、寬高深（公尺）、原點與正面朝向；註明實測或設計值。
- **外觀描述／參考圖 prompt**：用可直接製作參考圖的簡短描述，說明物件輪廓、配色、材質與必要細節；沿用專案低彩度工業恐怖風格。已有參考圖時附上連結。
- **交付位置**：GLB／貼圖放哪裡、可編輯來源放哪裡；只替換外觀，保留遊戲碰撞、互動及既有節點接口。

建築部件可各自建立 request，資料夾使用能識別建築與部件的名稱，例如 `shelter-entrance`。這類 request 補上所屬建築、相對父節點的位置與方向、接合尺寸及需保留的開口；建築整體配置與組裝仍由 Godot 場景維護。同一部件的重複實例共用一份 request。

有活動零件、插槽或骨架動畫時，才補上遊戲需要的名稱、位置／轉軸及動作要求；拆件、轉軸、綁骨與動畫依需求另行製作或接入，不預設 diffuser 輸出已具備這些功能。

完成情況：用一句話寫目前進度或尚待確認的事項，收到及接入模型後更新這一句。
