# 灰階暗部顯示與曲線

灰階顯示比較每個像素的原生亮度與材質參考亮度，白天的暗處和深夜都使用同一套判斷。原生照明足夠的表面保留光色；距離曲線只限制缺光表面能補多少灰階。深夜的室外環境底光為零，預設天空與霧的終端色為黑。近處保留灰階輪廓，遠處無光表面隨曲線衰減收黑。手電筒、車燈、車內燈、工作燈與遠處燈具的發光表面沿用原生光色及遮蔽。執行、重載與烘焙 LUT 都不會覆寫 [距離曲線](../../world/night_vision_curve.tres)。

選取正式世界的 `DarkAdaptation`，展開 Inspector 的 `profile`。室外與室外測試世界使用 [設定資源](../../world/dark_adaptation_profile.tres)，不再放在 `WorldClock`；獨立 POI 使用下方的專用室內設定：

| 欄位 | 預設 | 用途 |
|---|---:|---|
| `distance_begin` | 0 m | 曲線 X＝0 對應的距離 |
| `distance_end` | 60 m | 曲線 X＝1 對應的距離；須大於開始距離 |
| `curve` | 上述 Curve 資源 | 控制各距離保留多少灰階補光 |
| `reference_energy` | 0.06 | 參考亮度；越大，暗部能補足的細節越亮 |
| `dark_ratio` | 0.1 | 與 `lit_ratio` 的差值決定收尾的平滑區間寬度 |
| `lit_ratio` | 1.0 | 比例達此值時停止灰階補足；須大於 `dark_ratio` |

降低 `lit_ratio` 可讓較弱的燈光恢復原生光色；提高它會讓補光延續到較亮的區域。補光隨原生線性亮度增加而平滑歸零。`reference_energy` 設定中性參考的底光與亮度上限。

## 編輯控制點與切線

在 FileSystem 開啟 Curve 資源，展開 Inspector 的曲線編輯器。X 是距離區間內的比例，Y 是灰階補光的保留量：1 保留全部可補足的灰階細節、0 不加灰階補光。例如 0～60 m 區間中，X＝0.5 對應 30 m；該點 Y＝0.3 代表補上該處缺少亮度的 30%，不會將真實燈光壓到 30%。

新增或移動控制點可調整衰減位置；編輯點的左右切線可分別控制進入、離開該點的速度。想讓尾段緩慢收黑，可增加靠近右側的控制點，拉平接近 Y＝0 的切線。曲線可以先降再升，支援非單調形狀。亮度取樣會限制於 0～1，範圍外的切線過衝不會產生負亮度或超亮增益。

距離小於開始值時使用曲線左端值，大於結束值時使用右端值。右端 `(1, 0)` 代表結束距離外不再補灰階；真實燈光照到的物件與發光材質仍可看見。若右端大於 0，遠方也會保留灰階適應。過去曾以 `1 - pow(smoothstep(0, 1, t), 0.85)` 作為起始樣板；目前使用已保存的自訂曲線，不依該公式重建。

Y 控制灰階補光量；實際像素仍受物件材質、場景照明、天氣與畫面設定影響。已被真實燈具照亮的地方不需要同量補光，暗色物件的辨識度須在遊戲畫面中檢查。

## 副本的短距離灰階與黑暗

2026-11-03：地堡、巨型避難所及勤務樓梯間共用 [室內設定](../../world/instances/interior_dark_adaptation.tres)，與室外 profile／Curve 分離。室內 `reference_energy=0.06`，距離區間 0～5 m；獨立曲線從 0.72 開始，0.75 m 保留 0.68、1.5 m 保留 0.52、2.25 m 保留 0.28、3 m 起為零。近身保留較暗的灰階輪廓，三公尺外的無光表面收黑。相較上一版，距離恢復短範圍，曲線補光量整體降低 20%。這是即時顯示補償，不會隨等待時間逐漸變亮。修改室內設定不影響室外的 60 m 區間、0.06 參考能量與既有曲線。

`BunkerLighting.create_environment()` 為所有副本建立黑色背景、零環境底光，關閉環境反射填光。原生燈具維持自己的顏色與能量，照明半徑上限 7.5 m，衰減至少 1.6，搭配至少 0.12 m 光源尺寸的陰影及 SSAO 接觸遮蔽。熄燈房的燈管也不發光；鄰房燈光可經敞開門洞照入，實體牆仍遮光。手電筒主光程與電量不變，搬運大型物件時依靠既有亮燈區域及較短距離的灰階輪廓。

手電筒以較窄的主光斑加上較寬、較暗的 `Beam/Spill` 散光構成，兩者都使用陰影與[平方反比距離衰減](https://docs.godotengine.org/en/stable/classes/class_spotlight3d.html#class-spotlight3d-property-spot-attenuation)。主光程維持 24 m、散光 14 m，中心偏中性暖白、散光稍暖；Forward+ 另用徑向漸層 projector 軟化光斑過渡，Compatibility 使用聚光燈本身的角度衰減。沒有加入不受遮擋的發光錐體或環境填光。鏡片材質為每件物品獨立複本，只在實際照明時發光；主光源關閉時，散光與第一人稱複本同步關閉，耗電仍只由原物品計算。

## 在測試場重載

```powershell
godot --path . --log-file .godot/day-night-playground.log res://tests/day_night_playground.tscn
```

F1 循環切換清晨／中午／黃昏／夜間，並固定時間，用來觀察自然光變化。修改 Curve 後先儲存，再按 K，測試場會依目前 `profile.curve.resource_path` 重載並立即套用，即使時鐘停止也可觀察。使用另存的資源時，先將 `profile.curve` 指向該檔案；K 重載的是目前指定的已保存資源。

F8 是 Godot 編輯器的「停止執行」快捷鍵，從編輯器啟動時會結束遊戲，因此重載使用 K。

此測試場載入 `world/test_world.tscn`，與正式室外世界共用預設 profile 及 Curve。直接編輯室外共用資源會同時影響兩者，POI 則讀取自己的室內設定。執行中的 Remote Inspector 變更須另存資源才會保留。

## 手動 GPU 回歸

```powershell
godot --path . --script res://tests/support/night_vision_lighting_checks.gd
```

此檢查需要 GPU，請勿加 `--headless`，也不屬於預設核心測試程序。切換 Compatibility 可在命令加入 `--rendering-method gl_compatibility`；指定 Forward+ 則使用 `--rendering-method forward_plus`。

命令後加 `-- --blend-only` 可單獨檢查燈光逐步增強時的亮度、弱光顏色、強光與發光材質，以及灰階中的接觸遮蔽。

只驗證副本黑暗及與室外的差異時，命令後加 `-- --interior-only`。這會以正式室內環境／profile，檢查近距離微弱灰階、遠處全黑、正式手電筒開關與室外設定隔離。

2026-11-03 的副本專項結果、實際渲染及既有 GPU 檢查失敗另記於[本次驗證](../validation/2026-11-03-interior-lighting.md)。

檢查涵蓋固定照明下的日夜一致、同時段開關燈、正式手電筒與車燈、曲線為 0 時的原生光色、黑色材質、天空、陰影、濃霧遮蔽、獨立室內、鏡面、曲線編輯與世界轉移；另以清楚的物體輪廓檢查車架傾斜／側滾／位移及鏡面轉向後的第一幀，避免主圖與灰階參考晚一幀造成重影。同時確認原生 Environment 與已保存的 Curve 檔未被修改。場景中的材質、車窗與遠景觀感仍需透過上述測試場檢視。

## 畫面與限制

灰階顯示只影響 3D 世界，HUD 及顯示偏好的亮度／對比調整不參與缺光判斷。獨立 POI 使用自己的原生照明與更短、更暗的 profile，沿用相同的局部暗部演算法；時鐘只影響室外自然照明。自然霧仍可能遮住遠方燈光與物件，雨滴及水花直接接受場景燈光，不再按時段調色或使用夜間黑色遮罩。曲線及 profile 屬於場景／資源配置，沒有新增存檔欄位。

啟用時，系統用同姿勢、同投影的中性材質參考圖估計缺少的線性亮度。每增加一單位原生亮度，最多扣除一單位補光；接近 `lit_ratio` 時平滑收尾，再乘上距離曲線。微弱的原生光色會染色一部分補光。亮度充足、曲線值為零或深度對應天空的像素直接保留原生畫面。參考亮度上限為 `reference_energy`，純黑材質保持全黑。

參考圖使用黑色背景與距離霧，保留原視圖的距離霧及局部／全域體積霧遮蔽，並關閉全域體積霧的環境與 GI 注光。主圖保留原生燈光、霧中散射、材質發光與陰影。Forward+ 的參考沿用原視圖已啟用的 SSAO，Compatibility 在合成後套用原視圖的 SSAO。正式室外的體積霧關閉時間累積，讓手電筒與車燈的霧中光束隨當幀更新。玻璃與天氣接續透明繪製流程。微弱彩色照明可能被灰階柔化，霧的低解析度取樣及複雜透明材質也可能有差異。

每個活動視圖都有一次同 3D 縮放比例的參考幾何渲染，成本也包含白天；兩側鏡僅在各自刷新時更新參考。參考共用世界幾何，無額外遊戲模擬或燈光陰影 pass。Compatibility 保留原生距離霧，兩種渲染器使用同一條曲線。調整後應同時檢查暗色路面、燈具開關、受遮擋的陰影、遠方發光物及車窗／鏡面。
