# 灰階暗部顯示與曲線

灰階顯示依每處實際亮度運作，與時段無關：白天暗處也會補上灰階細節，夜間有充足照明的地方維持原生光色。手電筒、車燈、車內燈、工作燈及發光材質保留原有光程與陰影；距離曲線只限制灰階補足量。現有 [world/night_vision_curve.tres](../../world/night_vision_curve.tres) 的控制點與切線保持原樣，執行、重載與烘焙 LUT 都不會重設或覆寫資源檔。

選取正式世界的 `DarkAdaptation`，展開 Inspector 的 `profile`。室外、測試世界及獨立 POI 預設共用 [設定資源](../../world/dark_adaptation_profile.tres)，不再放在 `WorldClock`：

| 欄位 | 預設 | 用途 |
|---|---:|---|
| `distance_begin` | 0 m | 曲線 X＝0 對應的距離 |
| `distance_end` | 60 m | 曲線 X＝1 對應的距離；須大於開始距離 |
| `curve` | 上述 Curve 資源 | 控制各距離保留多少灰階補光 |
| `reference_energy` | 0.06 | 參考亮度；越大，暗部能補足的細節越亮 |
| `dark_ratio` | 0.1 | 原生／參考亮度比例低於此值時保留完整暗部反應 |
| `lit_ratio` | 1.0 | 比例達此值時停止灰階補足；須大於 `dark_ratio` |

想調整「多暗才有灰階」時，先調亮度比例，距離曲線保持不動。降低 `lit_ratio` 可讓較弱的燈光也恢復原生光色；提高它則讓灰階延續到較亮的區域。兩個比例之間使用平滑過渡。`reference_energy` 只供參考渲染，不會修改原場景的環境光或燈具能量。

## 編輯控制點與切線

在 FileSystem 開啟 Curve 資源，展開 Inspector 的曲線編輯器。X 是距離區間內的比例，Y 是灰階補光的保留量：1 保留全部可補足的灰階細節、0 不加灰階補光。例如 0～60 m 區間中，X＝0.5 對應 30 m；該點 Y＝0.3 代表補上該處缺少亮度的 30%，不會將真實燈光壓到 30%。

新增或移動控制點可調整衰減位置；編輯點的左右切線可分別控制進入、離開該點的速度。想讓尾段緩慢收黑，可增加靠近右側的控制點，拉平接近 Y＝0 的切線。曲線可以先降再升，支援非單調形狀。亮度取樣會限制於 0～1，範圍外的切線過衝不會產生負亮度或超亮增益。

距離小於開始值時使用曲線左端值，大於結束值時使用右端值。右端 `(1, 0)` 代表結束距離外不再補灰階；真實燈光照到的物件與發光材質仍可看見。若右端大於 0，遠方也會保留灰階適應。過去曾以 `1 - pow(smoothstep(0, 1, t), 0.85)` 作為起始樣板；目前使用已保存的自訂曲線，不依該公式重建。

Y 控制灰階補光量；實際像素仍受物件材質、場景照明、天氣與畫面設定影響。已被真實燈具照亮的地方不需要同量補光，暗色物件的辨識度須在遊戲畫面中檢查。

## 在測試場重載

```powershell
godot --path . --log-file .godot/day-night-playground.log res://tests/day_night_playground.tscn
```

F1 循環切換清晨／中午／黃昏／夜間，並固定時間，用來觀察自然光變化。修改 Curve 後先儲存，再按 K，測試場會依目前 `profile.curve.resource_path` 重載並立即套用，即使時鐘停止也可觀察。使用另存的資源時，先將 `profile.curve` 指向該檔案；K 重載的是目前指定的已保存資源。

F8 是 Godot 編輯器的「停止執行」快捷鍵，從編輯器啟動時會結束遊戲，因此重載使用 K。

此測試場載入 `world/test_world.tscn`，與正式世界共用預設 profile 及 Curve。直接編輯共用設定資源會同時影響兩者與 POI；若場景需要獨立設定，可將 profile 設為獨有資源，曲線仍可引用同一原檔。執行中的 Remote Inspector 變更須另存資源才會保留。

## 手動 GPU 回歸

```powershell
godot --path . --script res://tests/support/night_vision_lighting_checks.gd
```

此檢查需要 GPU，請勿加 `--headless`，也不屬於預設核心測試程序。切換 Compatibility 可在命令加入 `--rendering-method gl_compatibility`；指定 Forward+ 則使用 `--rendering-method forward_plus`。

檢查涵蓋固定照明下的日夜一致、同時段開關燈、正式手電筒與車燈、曲線為 0 時的原生光色、黑色材質、天空、陰影、濃霧遮蔽、獨立室內、鏡面、曲線編輯與世界轉移；另以清楚的物體輪廓檢查車架傾斜／側滾／位移及鏡面轉向後的第一幀，避免主圖與灰階參考晚一幀造成重影。同時確認原生 Environment 與已保存的 Curve 檔未被修改。場景中的材質、車窗與遠景觀感仍需透過上述測試場檢視。

## 畫面與限制

灰階顯示只影響 3D 世界，HUD 及顯示偏好的亮度／對比調整不參與缺光判斷。獨立 POI 使用自己的原生照明與同一套暗部規則；時鐘只影響室外自然照明。自然霧仍可能遮住遠方燈光與物件，雨滴及水花直接接受場景燈光，不再按時段調色或使用夜間黑色遮罩。曲線及 profile 屬於場景／資源配置，沒有新增存檔欄位。

系統用同姿勢、同投影的無實體燈光參考圖估計缺少的亮度，再按局部明暗反應及距離曲線加入灰階差額。以線性亮度計算：`原生圖 + 灰階(max(參考亮度 − 原生亮度, 0) × 暗部反應 × 距離曲線)`。暗部反應由原生／參考亮度比例平滑推導；參考接近零時不補足，以免純黑材質與數值雜訊發亮。天空與發光同時存在於兩張圖，不使用整張圖平均值，所以亮天空或局部燈光不會讓其他暗處失效。

參考圖保留原視圖的距離霧與局部／全域體積霧遮蔽，關閉參考環境光注入霧中的散射；主圖繼續保留原生燈光、材質、發光與陰影。正式室外的體積霧關閉時間累積，讓手電筒與車燈的霧中光束隨當幀更新，避免轉向或關燈後留下舊光束；灰階參考同步使用這個設定。霧的空間濾波及光照互動仍保留。這仍是缺光的視覺估計，不是精確照度或光照分解；微弱彩色照明可能被灰階柔化，霧的低解析度取樣及複雜透明效果也可能有差異。玻璃與天氣依透明繪製流程處理。兩側鏡各有同步參考，保持自己的距離視角。

每個活動視圖在日間與夜間都增加一次同 3D 縮放比例的參考幾何渲染，不增加遊戲模擬或陰影 pass；兩側鏡只在原定刷新時更新。體積霧依渲染器與畫質設定支援，Compatibility 保留原生距離霧。兩種渲染器使用同一條曲線。調整後應同時檢查暗色路面、燈具開關、受遮擋的陰影、發光物及車窗／鏡面。
