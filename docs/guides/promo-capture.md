# 宣傳影片錄影

從專案根目錄執行。啟動後等左上角出現 `Ready`，再按 F10 觸發鏡頭或按 F12 隱藏 HUD。

```powershell
./scripts/promo-capture.ps1 -Shot B3
./scripts/promo-capture.ps1 -Shot W1 -Variant 4 -Movie -Preview
./scripts/promo-capture.ps1 -Shot D3 -Movie -Preview -Exterior
```

`-Movie` 用 Godot Movie Maker 輸出 AVI，預設 1280×720、30 FPS。`-Fps` 可調整幀率，`-Format Png` 會改成影格序列。`-Preview` 自動觸發並在拍完後結束，適合軌道與試拍。`-Exterior` 搭配 `-Preview` 可在 O2、O4、D1、D2、D3 用車外鏡頭跟拍腳本駕駛。片段與日誌寫到 `.godot/promo-captures/`，每次啟動有獨立資料夾。Movie Maker 從啟動開始錄，剪輯時可裁掉等待段。需要即時操作的第一人稱鏡頭可用 OBS，在出現 `Ready` 後開始擷取。

| 按鍵 | 操作 |
| --- | --- |
| F7 / Shift+F7 | 重開同一鏡頭與變體／切到下一個鏡頭的預設變體 |
| F8 | 切換玩家視角與自由鏡頭。WASD 平移，Space／Shift 升降，滑鼠轉向，滾輪調速 |
| Shift+F8 | 依目前鏡位跟拍已擺場或觸發的主體。沒有主體時跟拍 RV |
| Ctrl+F8 | 慢動作／正常速度 |
| F10 | 執行下表動作 |
| Ctrl+F10 | 切換玩家無敵。拍攝抓咬與處決時維持關閉 |
| Shift+F11 / F11 | 記下當前鏡位／播放軌道 |
| Ctrl+F11 / Ctrl+Shift+F11 | 儲存本機軌道／清空本次編輯中的關鍵點。軌道按鏡頭和變體存在 `.godot/promo/` |
| F12 | 切換乾淨畫面。平板操作仍可拍，拍施工或列印結果時再關平板 |

## 地堡

B1–B6 共用世界種子 42，入口 `v20:42:stop:3`，地堡種子 1995642334。這座地堡包含 54 間房、兩層。探索鏡頭沿用正式照明、房間及內容。B5 採切除天花板的拍攝視圖。

| 啟動參數 | F10 | 拍攝方式 |
| --- | --- | --- |
| `-Shot B1` | 開手電筒 | 沿光束前進。E 撿零件、靠近補給箱長按 E 搜索 |
| `-Shot B2` | 暗房出現黑影 | 手持手電筒按右鍵把光打向黑影。可先定位側面鏡位再 F8 回第一人稱照亮 |
| `-Shot B3` | 放行 Raker | 先開手電筒再觸發，讓 Raker 接近。抓住時重複按放 Space，抓咬版可用 `-Preview` 重現受傷掙脫 |
| `-Shot B4` | 放行油桶人 | 第一人稱對準油桶列，預留後退距離，錄起身、追擊與自爆 |
| `-Shot B5` | 切換樓層並播放軌道 | F11 播目前樓層。用 `-Variant 1 -Movie -Preview` 拍下層 |
| `-Shot B6` | 拾取強化引擎 | 扛著引擎沿走廊回出口。可先開 M 檢查地圖再關閉拍攝 |

## 公路與戶外

駕駛使用遊戲設定中的油門、方向與換檔操作，預設 W 加速、S 煞車、R 升檔、T 降檔。可先用第一人稱錄儀表和操作，再用 `-Exterior` 重錄外景。

| 啟動參數 | F10 | 拍攝方式 |
| --- | --- | --- |
| `-Shot O1` | 放行路邊油桶人 | 先對準油桶列，再拍起身追人 |
| `-Shot O2` | 發動並放手煞車 | 對準前方路上的普通油桶，加速撞擊 |
| `-Shot O3` | 依白影生成規則現身 | 先拍據點與散落零件。觸發後轉頭找白影，直視可拍 SAN 下降及異常畫面 |
| `-Shot O4` | 放行巨人、發動並放手煞車 | 沿霧中公路加速，從車外拍巨人追上、揮擊車體。車外版本用 `-Exterior` |
| `-Shot O5` | 放行巨人 | RV 停在路上，駕駛側板已受損。等巨人接近、擊穿前頂板後抓住駕駛。可從駕駛座拍，或用 F8 到車外取景 |
| `-Shot D1` | 發動並放手煞車 | 沿路肩對準三棵小樹，拍連續撞倒 |
| `-Shot D2` | 發動並放手煞車 | 對準釘帶，壓過後避開廢車 |
| `-Shot D3` | 發動並放手煞車 | 在直路逐檔加速，拍實體儀表，再錄車外鏡頭 |
| `-Shot D4` | 釋放側傾 RV，再按可嘗試部署千斤頂 | 等 RV 停穩，移到可抬升的一側，選取千斤頂並對準車身操作 |
| `-Shot D5` | 放手煞車 | 從路肩拍車倒滑，再追上去 |

## RV 車內

| 啟動參數 | F10 | 拍攝方式 |
| --- | --- | --- |
| `-Shot R1` | 將下一件擺好的物品放入分解機 | 按順序投入廢料、油桶和遇難者遺體。兩件之間等分解完成。手動拍時可自行搬運、投料。遺體已缺雙臂，便於放入實際分解機入口 |
| `-Shot R2` | 開啟 Crafting | 按 `Add to queue`，再關平板拍列印。`-Variant 0/1/2` 分別預選 Battery、Wheel、Standard Engine |
| `-Shot R3` | 開啟 Structure | 平板選 Front roof 修理、Right rear 重建。施工完成後關平板拍結果。安裝設備時先關平板，對準平坦車板按 F 再確認預覽位置 |

## 主世界

| 啟動參數 | F10 | 拍攝方式 |
| --- | --- | --- |
| `-Shot W1` | 播放公路空拍 | 主鏡頭和 `-Variant 1/2/3/4` 提供不同路段。分開拍攝後串接橋、丘陵、峽谷和森林 |
| `-Shot W2` | 播放對照軌道 | 分別錄 `-Variant 0/1/2`，以相同道路里程和鏡頭節奏比較種子 42、43、44 |
| `-Shot W3` | 觸發日夜及天氣縮時 | 由清晨開始，約 12 秒跨越一個遊戲日，用軌道拍天色與霧的變化 |

掃描其他地點可以使用正式世界的生成規則。結果寫到 `.godot/promo/scout.json`，包含地堡、路段坡度、地區權重、油桶與釘帶等候選。

```powershell
godot --headless --path . --script res://scripts/promo_scout.gd -- 42 43 44
```

完整逐鏡回歸可在 Godot 的無畫面模式執行。日常測試涵蓋各類代表鏡頭。逐鏡檢查會重建正式世界多次。

```powershell
godot --headless --fixed-fps 60 --path . --script res://tests/test_promo_world.gd -- --all-takes
```
