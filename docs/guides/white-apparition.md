# 白影遭遇

外觀使用 Blender 製作的一體式蒙皮，保持無臉、細腰、長指與模糊白色輪廓，不使用分段圓球關節。動作在蛇行側折、腰胸反向扭轉、甩臂抬膝踏舞之間切換，頭與手腕延遲跟隨，穿插短促抽搐和停頓；兩層延遲殘影拖曳在動作後方。注視點跟隨實際骨架的胸與頭。這次蒙皮與大幅舞動修訂依使用者要求未重新執行回放或視覺檢查。

離開開局避難所後，正式世界與展示世界都會在符合條件的戶外遊玩時間累計 25–40 秒後啟動白影遭遇。開局準備、暫停、設定畫面和玩家遭抓取時停止計時或注視判定。進入獨立室內、玩家死亡或載入檢查點會清除進行中的遭遇。

以玩家當前的畫面視角判定注視，駕駛時使用駕駛視角。白影胸口須在畫面中央 40% 寬高範圍內，頭部須在畫面中，且兩處視線皆未受遮蔽。持續 0.6 秒才算一次有效注視。前兩次有效注視後白影消失，等待 4–8 秒再找新的出現位置。連續 60 秒沒有符合上述條件的視線就清除計數。第三次有效注視會發出 `threshold_reached` 訊號，白影短暫停留後淡出，並等待 90 秒才開始下一輪。

遭遇僅存在於當前載入的世界，進度不寫入存檔，也沒有多人同步。第三次注視只發出訊號，目前沒有實作幻覺或相關效果。

用 `godot --path . res://tests/white_apparition_playground.tscn` 開啟霧地測試場。加上 `-- --replay` 會使用玩家視角自動注視自然出現的白影，將截圖寫入 `.godot/white_apparition/context.png`，並在第三次注視確認後結束。
