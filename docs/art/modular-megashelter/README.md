# 模組避難所美術基準

[reference.png](reference.png) 是本次對話於 2026-10-27 以內建 ImageGen 產生、使用者要求實際模型貼近的概念圖。不是遊戲截圖，也不是既有模型。

製作時保留：厚重且高出屋頂的混凝土直柱、跨多層的封閉大牆塊、深凹水平設備帶、低飽和灰綠與混凝土色、厚入口及鏽蝕鋼門。比例、幾何厚度、剝落與收邊必須由實際模型呈現；不能只用平牆、水痕或霧代替。

圖中的尺寸與零件數為示意，正式規格見[製作指南](../../guides/megashelter-exteriors.md)。目錄以 `.gdignore` 排除 Godot 匯入。
