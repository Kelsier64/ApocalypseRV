# POI 後續開發計畫

- 建立日期：2026-09-15
- 狀態：**2026-09-22：室內 v2 已接入新訪副本；11 種灰盒房型、兩層、零件庫、返程捷徑及探索／版本化保存。完整驗收結果見 [本輪紀錄](../validation/2026-09-22-interior-v2.md)。專屬主題、第三層、遭遇導演與長局平衡仍待擴充。**
- 來源：目前 POI 實作檢視與使用者討論。
- 範圍：保存本輪所有改善方向、建議順序、依賴與驗收條件。列出的玩法選項仍需在實作時收斂，不表示每個例子都已確定採用。

## 1. 目前基礎與保留原則

- 四款非 legacy 入口的新副本使用 maintenance_v2；既有 actor-only 已訪副本保留 v1 單層幾何。轉場、World3D 隔離、室外持續模擬、串流錨點及返回安全流程沿用。
- 正式 v2 總房數 50–100，兩層、11 種灰盒房型。必要 12 房路線連接挑高廳、兩座樓梯及零件庫，其餘依 seed 從房型表沿三維接口擴展；不再固定 27 m 房間間距。
- 一般淨高 5.5 m、跨層房 11.5 m、樓層間距 6 m；完整三維占用保留挑高和樓梯空間。第三層仍未啟用。
- 零件庫 E 一次提供一個標準引擎與兩包維修包；從深處側可開返程門。三個路程區域、上下樓線索及 M 分層已探索地圖已接入。
- 一般物資總上限 36／每房 2，入口保證汽油罐；目標另有 3 件。敵人至多 8，使用獨立 RNG，依入口路程選支路房。仍沿用既有殭屍 AI。
- 新保存包含釘選生成器／內容版本、房間 ID／transform、接口連接、目標、門閂、探索及 actors。重返不重抽，未知版本拒絕；室外 F6／F9 沿用檢查點 v3。
- 每次進入仍重建與烘焙全部房間，已增加 50／75／100 房首次／重返量測；尚未實作分區串流與長時間群體效能驗收。
- v5 公路可回程重建，加油站 WALK_IN 與場內物資保存沿用；任意散落物永久保存仍不提供。

- v5 已有同世界可步行探索的加油站，依 PoiDefinition 占地整地；場內剩餘道具／鬆散設備／活怪在卸載、回訪與磁碟還原時保存。加油機仍是造景，未提供燃油交易。

維持「手工房間＋程序連接、模型／碰撞／標記分層」方向。11 種是可辨識灰盒模組數，50–100 是房間實例總數；不宣稱完成 100 套美術或每個 seed 重排必要主路。完整製作契約見 [室內 v2](../guides/interior-v2.md)。

## 2. 工作項目

優先級是建議開發順序，不是已承諾的時程。

| 編號 | 優先級 | 工作項目 | 主要目的 |

| POI-02 | P1 | 房型與布局變化 | 減少兩種模板重複與規整格網感 |
| POI-03 | P1 | 迷路與返程體驗 | 保留迷宮感，減少無意義的回頭路 |
| POI-04 | P1 | 物資與搬運平衡 | 配合背包容量、探索深度和風險 |
| POI-05 | P2 | 敵人配置與室內應對 | 建立可理解的危險分布與逃生選擇 |

### POI-01：深入探索的理由

現況：v2 已有零件庫目標、一次性實物獎勵與按連通路程配置的補給；仍需長局收益調校。

待做：

- [x] 為維修站安排至少一個深處目標，例如零件庫、供電控制室或特殊設備；實作時選定具體內容。
- [x] 按入口的實際連通路程安排入口區、過渡區與深處區，不使用房間編號代替距離。
- [x] 探索深度納入上下樓的實際路徑成本；樓層高低不直接等於難度或獎勵等級。
- [ ] 設計「現在撤退」與「繼續深入」的取捨，讓可見線索提示更深處的收益和危險。
- [x] 保存目標完成與相關互動狀態，離開重返不重置。

驗收：從入口到目標可達；不同 seed 都能形成可理解的探索流程；一般搜刮與完成深處目標有可辨識的收益差異。

### POI-02：房型與布局變化

現況：v2 共有 11 種房型，包含不同尺寸、旋轉、樓梯與挑高房；原兩種平面房保留給舊副本。

待做：

- [x] 第一輪擴充到 8–12 種可辨識房型，候選包含長房、L 型房、交叉廳、儲藏間與不同尺寸的大廳。
- [x] 房型預算納入 POI-10 的樓梯房與跨層挑高房；跨層房算一個房間實例，但占用完整三維空間。
- [ ] 增加可探索的樓上環廊／平台房型（目前挑高廳上方構件僅造景）。
- [x] 為房型製作不同家具配置，保持門口與主要通路淨空。
- [x] 擴充占地、門位置、旋轉與連接規則，逐步支援不等寬、不等長與不同門數的房型。
- [ ] 控制房型權重、相鄰重複與特殊房數量；保留 50–100 房總量及全部房間連通。
- [x] 改善固定 27 m 間距造成的走廊長度與規整感，避免新增房型後重疊或留下無法穿越的接口。

驗收：新房型有獨特用途或動線；混合尺寸與旋轉生成時不重疊、不封死必要通路；物理行走和導航皆能通過連接處。

### POI-03：迷路與返程體驗

現況：v2 有三區色標、樓層／方向提示、已探索分層地圖與返程門；出口在接待室。

待做：

- [x] 劃分至少三個可辨識區域，以色帶、用途、照明或地標提供方位線索。
- [x] 加入玩家標記或探索紀錄；具體形式可選已探索地圖、路徑記錄或場景標記，不預先揭露整座迷宮。
- [x] 顯示目前樓層、樓梯上下方向及已探索的跨層連接；探索記錄支援分層檢視，避免不同高度的房間混在同一平面。
- [x] 設計從深處開通的返程捷徑，讓探索成果能縮短搬運與撤退路程。
- [x] 保存已探索資訊和捷徑開啟狀態，避免重返後消失。

驗收：玩家能藉環境線索識別區域；找到目標後有更有效率的返回方式；導航輔助不直接消除未知區域的迷宮感。

### POI-04：物資與搬運平衡

現況：v2 改為總物資預算 36／每房 2 件，目標 3 件另計；背包仍為 6 格，搬運經濟尚需長局調校。

待做：

- [x] 設定副本總物資預算、區域物資類別與價值分布，避免單純按房數堆量。
- [ ] 依探索深度、房間用途與風險調整獎勵，保留靠近入口的基本補給。
- [ ] 評估推車或暫存點的必要性；先測量現有搬運成本，再決定採用方案。
- [x] 結合返程捷徑，避免大型物品只能反覆走相同長路。
- [x] 驗證搬運大型物品上下樓的通行空間；若採推車，需先決定其樓梯限制與替代搬運路線。
- [ ] 驗證物資供給能支援搜刮、回收、製作汽油及再次出發的循環。

驗收：完整遊玩一趟後記錄搜刮時間、滿包時機、搬運次數與實際收益；深入的收益應能支持其額外風險與時間成本。拾取、搬運、暫存及重返不得複製物品。

### POI-05：敵人配置與室內應對

現況：v2 不再按房號撒怪；在入口路程超過 35 m 的支路房間配置至多 8 隻。跨層尋路沿實體樓梯，未新增巡邏或遭遇導演。

待做：

- [ ] 改成依入口距離、區域危險度與房間用途配置敵人，保留入口緩衝。
- [ ] 規劃巡邏、固定守備與群體出現的配置規則，避免單純平均撒怪。
- [ ] 提供室內躲避、引誘或關門等應對方式；具體機制在實作時選定，不預設必須加入武器。
- [ ] 驗證窄門、家具、轉角與多隻敵人的實際追擊與脫離行為。
- [ ] 驗證敵人能沿樓梯跨層追擊和撤離；同 X/Z、不同樓層的玩家不得被隔著樓板攻擊或誤認為可直走抵達。
- [x] 保留敵人不跨入口的隔離規則，並維持同局死亡狀態。

驗收：危險分布與環境線索相符；玩家有可操作的應對或撤退路徑；敵人不穿牆、不跨世界攻擊，群體不長期卡死必要通道。

### POI-06：入口與地形整合

現況（2026-09-22 核對）：路旁停車區、支道、入口平台與三種小補給點已有；四款副本入口仍共用相同室內內容。另有正式 v5 加油站，以資產占地整地並清空植被，支援同世界步行探索。[地形驗收](../validation/2026-09-15-highway.md)、[正式加油站驗收](../validation/2026-09-20-production-gas-station.md)。

待做：

- [x] 建立公路、停車區、支道、入口平台之間的安置規則。
- [x] 限制坡度、落差與道路距離，檢查 RV 停靠空間、步行動線與返回落點。
- [x] 增加四款入口外觀，見 [室外驗收](../validation/2026-09-16-outdoor-horror.md)。
- [x] 第一棟 WALK_IN 加油站接入正式世界，沿用共用資產定義、占地整地、導航與物資保存；其他新建築仍須各別驗證。
- [ ] 由 POI 類型選擇不同房間、物資與敵人配置。
- [x] 與地形重寫整合，讓既有入口模板落在整平平台並朝向公路；新模板仍須驗證各自占用範圍。

驗收：多組世界 seed 的入口可從公路抵達；RV 有合理停靠空間；玩家進出後不被地形、建築或停放車輛困住。

### POI-07：效能與異常復原

現況：每次進入都重建所有房間並烘焙導航；轉場失敗／逾時／取消復原已有 [R05 修正與測試](../report/ApocalypseRV_Fixes_2026-09-18.md)，大型副本長時間效能與下列完整情境仍需驗收。

- [ ] 先量測 50／75／100 房的首次載入、重返時間、幀率、記憶體及敵人處理成本，再設定效能目標。
- [ ] 納入不同樓層數、挑高跨層房與多層可見區域；遠處休眠與分區載入需考慮垂直距離及跨層追擊。
- [ ] 依量測結果評估布局／導航快取、遠處敵人休眠與分區載入；避免未量測就全面改架構。
- [x] 轉場失敗、逾時、取消與死亡時清理暫建世界並恢復控制，見 R05。
- [ ] 完善可量化載入進度，依 50／75／100 房量測驗收。
- [ ] 測試快速重複互動、轉場時死亡、返回位置被占用等邊界情境。
- [ ] 驗證多次進出不同 POI 後記憶體不持續無界成長，沒有殘留物理物件或子視窗資源。

驗收：記錄量測設備、引擎版本與效能數據；故障時不得永久停在 busy 或 UI 鎖定狀態；最佳化後保持同局保存、世界隔離和導航行為。

### POI-08：存檔與長期回訪

現況：v2 的布局、探索、目標與捷徑已納入現有室外檢查點；保留 v1 幾何且拒絕未知內容版本。v5 有回程串流基礎，多種副本入口的遠距往返仍需專項驗收。

- [x] 定義穩定的世界、入口、副本與互動物件 ID，及存檔版本與升級策略。
- [x] 透過室外檢查點保存既有布局 seed、物品與敵人狀態。
- [x] 擴充探索紀錄、目標、門與捷徑狀態。
- [x] 保存生成器版本、房間穩定 ID、三維 transform、跨層連接及必要的樓層識別；不可只用平面座標辨識房間或物品。
- [x] v5 可重建回程區塊，入口以原 site.id 註冊；WALK_IN 加油站回訪恢復已保存物件，不重抽物資。
- [ ] 補足多種副本入口在遠距卸載、回程、跨執行載入後仍連回原副本的專項驗收；現有加油站驗收不能代替此項。
- [x] 處理讀取失敗、缺少資源及不相容版本，避免悄悄重置已搜刮內容。

驗收：離開遊戲後重開仍還原相同副本；外部區塊卸載與重建不產生新的副本身分；已拿物品與死亡敵人不重生。

### POI-09：房型資源表與製作工具

現況：新增普通支路房型可透過場景與 InteriorRoomDefinition／InteriorProfile Resource 登錄。必要主路的重排仍屬生成設計修改。

已建立 PoiDefinition 與共用 POI 素材目錄，集中六份室外資產的類型、場景、場址與入口資料；既有四款入口和正式 v5 加油站使用同一規範。此為室外定義基礎；2026-09-22 的室內房型表與三維接口另見本輪 v2 規格。未勾選的複合項目不表示所有子項都未做；兩層／直線樓梯已完成，第三層及轉折樓梯保留後續。見 [共用規範](../guides/poi-authoring.md)。

- [x] 建立室外 PoiDefinition 目錄，區分副本入口與直接探索型，明確分離模型、碰撞、入口和物資標記。
- [x] 建立可在 Godot 編輯器配置的 POI／房型資源表，包含場景、尺寸、門接口、權重、區域、家具與物資配置。
- [x] 配合 POI-10 加入三維占用範圍、跨層高度、各入口的完整 transform 與通行方式；樓梯上下端可有不同 Y 值，不能再假設所有門都在同一高度。
- [x] 讓生成器讀取資源表，降低新增房型時修改生成程式的需要。
- [ ] 提供指定 seed 的一鍵預覽、重新生成、單房檢查及布局總覽。
- [ ] 預覽支援切換樓層、剖面或隱藏上層幾何，讓樓梯、樓板與跨層碰撞可直接檢查。
- [ ] 加入尺寸、接口、通道淨空、重複 ID、缺少資源與標記位置的驗證回饋。
- [x] 保持模型外觀、碰撞、門接口與物資點分層，方便正式模型逐步替換灰盒。

驗收：能透過新增資源與場景加入一種房型；不相容內容在製作階段即可定位；預覽與正式遊戲對相同 seed 使用相同生成規則。

### POI-10：三維布局與上下樓房間

現況：v2 已升級為 X/Y/Z 空間中的兩層迷宮；舊副本保留平面生成。玩家在同一副本內實際走樓梯上下移動，不以逐層傳送取代樓梯通行。

待做：

- [x] 將布局資料、占用檢查與連通圖改為支援三維座標及帶高度的連接；上下樓屬於同一張探索拓樸，不是彼此無關的平面迷宮。
- [ ] 定義樓層標高、樓板厚度、淨高與垂直模組規格，區分房間淨高和樓層間距；先以可配置的 2–3 層驗證，實際上限依內容與效能決定。
- [ ] 製作樓梯房，包含低處入口、階梯、轉折平台與高處出口；也能從高處往低處通行。優先完成一般步行樓梯，梯子、電梯保留為後續擴充，不恢復已刪除的舊電梯生成器。
- [x] 製作跨層挑高房、樓上平台或帶內部樓梯的雙層房，讓上下樓可發生在同一房間內；上下接口不必位於相同 X/Z。
- [x] 為房間定義完整三維占用體積或占用格集合，包含樓板、樓梯、平台和必要淨空；挑高空間不可被另一層房間填入。
- [x] 依門接口的完整 transform 接合房間與垂直連接模組，檢查高度、朝向、開口尺寸、樓梯終點與頭頂淨空；不能只把既有房間任意抬高。
- [x] 生成時安排必要的跨層連接，檢查所有可探索房間都能從主入口抵達並沿合法路線返回；支援由不同樓梯構成的跨層環路與返程捷徑。
- [x] 處理樓梯碰撞、步高或斜坡碰撞代理、平台接縫與護欄，確保正式玩家能連續上下樓且不必每階跳躍。
- [x] 烘焙或連接各高度的可行走導航，處理樓梯與平台；若使用導航連結，必須對應角色實際能完成的通行，不可讓導航跨越實體樓板。
- [ ] 樓梯和高處平台的家具、物資與敵人點需有可靠支撐，避開踏步動線、孔洞和樓板內部。

驗收：

- 同 seed 可重現相同三維布局，總房數維持 50–100；跨層房不因占用多層而重複計數。
- 多 seed 測試不存在三維重疊、挑高空間被填滿、懸空門、階梯頂頭或孤立樓層。
- 正式玩家能由入口連續上樓、進入上層房間、經另一條跨層路線下樓並返回；攜帶大型物品時也能通過規定的搬運路線。
- 殭屍能使用同一樓梯尋路，跨樓層偵測及攻擊受到實際視線與通行條件限制；不能穿樓板、直接跳層或卡在平台接縫。
- 每個重要目標有有效抵達與撤退路徑；返程輔助能分辨樓層與上下樓方向。
- 離開重返後房間高度、物資位置、敵人狀態、探索紀錄與跨層捷徑狀態保持一致。

依賴：先與 POI-09 一起確定房間／接口的三維契約，再擴充 POI-02 的房型。POI-01、03～05 的目標、返程、搬運與敵人配置都須依實際跨層路徑工作；效能與保存分別由 POI-07、08 延伸驗收。
