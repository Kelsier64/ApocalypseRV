# 室外恐怖氛圍與離路物資點

## 已確認設計

公路辨認建築 → RV 停車 → 穿過視線遮蔽路線 → 進入既有副本 → 攜物資回車。

- 室外固定陰天、灰綠／土褐工業風格、低面數造景與距離霧。
- 復古 3D 畫面約 540 像素高，固定微量抖色；HUD 保持原解析度。F8 切換並獨立保存偏好。室內停用室外效果。
- 主要建築離道路 100–160 m；步道 150–250 m，正式玩家約 30–50 秒單程。
- 停車灣至少 12×24 m，步道 2–3 m、坡度不超過 20°；必經實體窄口 1.6–1.8 m。
- 建築高輪廓可從停車處辨認；沿途至少兩個遮蔽段，植被、土坡與設施圍牆交錯。路標引路，不加浮空箭頭。
- 四款入口：維修廠／煙囪、倉庫／水塔、泵站／槽體管線、研究站／天線。保留 Entrance 與 ReturnPoint 契約及現有室內迷宮。
- 三個停靠點中兩個主要入口、一個低收益小補給點；小點保留廢車、營地、養護棚，1–2 件普通物資。

## 實作契約

`WorldField.stop()` 共用場址計畫供整地、造景、建築、導航與串流查詢。有限路線模板依 seed 鏡像，不無限重抽。場址不超出既有 450 m 寬碰撞地形。

新世界使用生成 v3；checkpoint 格式仍為 v3，以獨立 generation_version 保存生成版本。缺少欄位的舊存檔視為生成 v2，維持原位置、碰撞配置、POI ID 與室內 seed。

導航涵蓋可探索地形及窄口，跨帶連通；玩家在場址／副本期間保留完整場址相關 chunks。造景細分影格建立，導航非同步烘焙。

## 驗收

100 個 seed 的可重現性、路程／坡度／支撐／邊界；正式玩家攜引擎進出副本與油桶回程；正式怪物通過交錯窄口；正式 RV 輪驅進停車區、窄口阻擋及煞車；新舊 checkpoint、UI 與顯示切換；全測試 runner。

四款外觀各記錄公路、停車處、遮蔽步道、入口、回望視角，並記錄實際步行時間、影格時間與生成停頓。結果見 [驗收紀錄](../validation/2026-09-16-outdoor-horror.md)。

本輪不擴充室內布局、動態天候、日夜、聲音、新怪物或驚嚇事件。未宣稱霧或無碰撞灌木提供潛行機制。
