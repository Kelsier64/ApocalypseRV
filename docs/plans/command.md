# 局內指令系統設計

## 目標與開關

建立純文字控制台，提供時間、天氣、怪物／道具生成、無限油，以及玩家第三人稱。控制台開啟時世界繼續運作。

- Godot 專案設定增加 `debug/commands/enabled`，預設關閉。
- 啟動參數 `-- --debug-commands` 啟用，`-- --no-debug-commands` 強制關閉；強制關閉優先。
- 關閉時不建立控制台、不接管快捷鍵，執行入口也拒絕指令。
- 按 **F10** 開關控制台，**Esc** 關閉，**Enter** 執行。提供中文說明、Tab 補全、上下鍵歷史紀錄。
- 暫時模式由各個世界持有；成功讀檔後重設，讀檔失敗則保留原世界狀態。

## 指令與行為

命令使用英文名稱、中文回饋；忽略大小寫與多餘空白。錯誤參數顯示用法，不修改世界。

| 指令 | 行為 |
|---|---|
| `help [指令]` | 列出指令或查看用法 |
| `status` | 顯示時間、天氣、凍結、無限油與鏡頭狀態 |
| `clear` | 清除控制台輸出 |
| `time set HH:MM [天數]` | 設定時間；省略天數時保留目前日期 |
| `time freeze on\|off` | 凍結／恢復時間推進 |
| `weather set <類型>` | 立即切換天氣 |
| `weather set overcast <雨級> <霧級>` | 組合陰天、雨與霧；等級為 0／1／2 |
| `weather freeze on\|off` | 凍結／恢復天氣演變 |
| `list enemies\|items` | 列出可生成 ID 與中文名稱 |
| `spawn enemy <ID> [數量]` | 在玩家附近生成怪物 |
| `spawn item <ID> [數量]` | 在玩家附近生成地面道具 |
| `fuel infinite on\|off` | 切換本局 RV 的無限油 |
| `camera thirdperson on\|off` | 切換玩家第一／第三人稱 |

天氣類型固定為 `clear`、`overcast`、`light_rain`、`heavy_rain`、`light_fog`、`heavy_fog`。雨霧可同時存在；晴天不搭配雨霧。時間與天氣凍結互相獨立，凍結天氣不會停止雨滴動畫。

例如：

```text
time set 21:30
weather set overcast 2 2
weather freeze on
spawn enemy raker 3
spawn item gas_can 5
fuel infinite on
camera thirdperson on
```

## 實作與整合

**控制台與輸入**

- 新增 `DebugCommands` autoload，管理外部開關、命令登錄、執行入口與輸出；控制台沿用 IndustrialTheme，顯示於主視窗上層，副本內也能使用。
- 玩家增加 `is_gameplay_input_blocked()`，統一阻擋移動、跳躍、互動、維修、快捷欄、鏡頭與駕駛輸入；同步阻擋副本地圖、輸入轉送和檢查點快捷鍵，避免打字触發玩法。
- 輸入鎖與既有 UI 模式分開：重力、傷害、車頂跟隨、攀爬接觸和車輛物理持續更新。駕駛輸入歸零，車輛依既有物理繼續滑行。
- 可從一般狀態、攀爬及駕駛開啟；其他介面、放置、死亡、被抓或轉場期間拒絕開啟。被抓、死亡或世界切換時自動關閉，讓原流程接管滑鼠與鏡頭。

**時間、天氣與生成**

- 沿用 WorldClock／WorldWeather，增加不入存檔的獨立凍結旗標，保留 StartRun 對整備期的控制。副本中的時間／天氣指令作用於所屬戶外世界。
- 怪物先支援現有 `raker`；道具沿用 SaveSceneCatalog 的 11 種 Prop。補全與執行共用白名單。
- 透過目前世界及 POI 管理器取得實際玩家，生成至 `WorldEntities.get_container(player)`，排除讀檔候選世界。
- 數量預設 1，每次限 1–20。依玩家觀看方向搜尋附近落點，檢查地面、實際碰撞形狀與物件間距；怪物額外要求有效導航。
- 生成查詢於物理步執行，每步最多生成 2 個；回報實際完成數量。轉場或讀檔開始時取消尚未生成的部分。
- 每個物件獨立初始化 ID，加入場景前先設定位置。整備期生成的怪物仍遵守 StartRun 的休眠規則，控制台明確提示。

**無限油**

- 由目前世界持有模式，套用至該世界既有與後續建立的 RV。
- 統一燃油可用量與耗油判斷，涵蓋啟動、怠速、行駛、發電機保留油量、音效與燃油警告。
- 啟用時不扣油，也不灌滿油箱；HUD 標註無限油並保留實際油量。關閉後按原油量恢復運作。
- 引擎故障、電池容量、供電、輪胎與行駛互鎖維持既有判定。

**自由環繞第三人稱**

- 新增玩家鏡頭控制器，保留既有第一人稱眼部鏡頭作為抓取、死亡及身體接觸基準。
- 第三人稱滑鼠只轉鏡頭；WASD 依鏡頭的水平朝向移動，玩家平滑轉向移動方向。攀爬保留 W 向上、A／D 橫移與既有脫離操作。
- 預設距離 3.2 m，沿用滑鼠靈敏度及上下 80°限制；使用半徑 0.2 m 的相機碰撞查詢，排除玩家自身，遇障礙立即縮短、離開後平滑恢復。
- 第三人稱顯示完整模型，排除第一人稱局部模型副本。互動依畫面中心選目標，再從玩家眼部檢查遮擋與距離，保留互動 3 m、放置 4 m 的限制。
- 入座、被抓與死亡時使用原有專用鏡頭；離座、脫困或重生後恢復所選模式。切回第一人稱時將玩家朝向對齊目前觀看方向。
- 同步修正互動與設備放置的瞄準入口，支援戶外、副本、攀爬及車頂移動。

## 保存與驗收

- 生成物、調整後時間／天氣沿用既有保存與串流規則；成功讀檔後，無限油、第三人稱及兩種凍結模式重設。無須新增存檔欄位。
- 新增命令解析與開關測試，涵蓋參數錯誤、補全白名單、數量界限及關閉時無副作用。
- 整合測試涵蓋戶外／副本生成歸屬、阻擋落點、唯一 ID、導航、整備期休眠，以及成功／失敗讀檔的模式處理。
- 擴充能源與天氣測試：零油啟動與發電、模式關閉、故障引擎、真實油量保存，以及獨立凍結和立即刷新。
- 第三人稱測試涵蓋環繞、相機方向移動、牆邊縮短、模型圖層、互動遮擋、放置、攀爬與鏡頭交接。
- 新測試分類至 `tests/suites.json`；執行相關回歸及正式主場景 smoke。依 AGENTS.md 另做實機驗收，確認輸入不洩漏、移動 RV 上保持支撐及副本操作；實機觀察與自動測試分開記錄。
- 更新 README／architecture 的開關與操作說明，保留目前工作樹的其他修改。
