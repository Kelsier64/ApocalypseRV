# RV 擬真操控、翻車、車損與玩家受傷

日期：2026-11-14。狀態：**首版已接入正式場景，駕駛手感與聽感待試玩驗收**。本計畫接續 [RV 駕駛體驗](2026-09-16-rv-driving-experience.md)，並處理[計畫總覽](README.md)中「撞車車損」的待辦。

## 目標

- 開起來像一台重車：有側傾、點頭、推頭、甩尾，柏油與泥地抓地不同。
- 會翻車，但正常駕駛不會無故翻車。
- 撞擊與翻車造成有位置差異的車損，不再只扣引擎。
- 車禍會傷到玩家，嚴重時斷肢或死亡。
- 玩家離開行駛中的 RV 後，落地或撞到障礙物時可能受傷。
- 翻車後有辦法救回來，不會卡死存檔。

## 已確認的設計決定

| 題目 | 決定 |
|---|---|
| 物理底層 | 混合式：保留 `VehicleBody3D` 的懸吊與車輪節點，輪胎力、煞車、傳動自寫 |
| 翻車門檻 | 擬真但寬容：平地柏油先滑不先翻 |
| 翻車脫困 | 需要救援裝備 |
| 玩家受傷 | 扣血、暈眩、甩飛，加上斷肢 |

以下是我代為決定、你可以否決的項目：

- 救援裝備先做**高舉式千斤頂**，不做絞盤。絞盤需要錨點和纜繩，範圍大很多。
- 千斤頂的保底來源：`starter_kits` 車輛出廠附一支，教學第二室放一支，製作台可重做。
- 翻車狀態允許存檔。翻倒只是車身姿態，快照本來就存姿態。
- 一次車禍最多斷一肢，不斷頭。
- 倒置只讓引擎熄火，不額外扣引擎耐久，也不做漏油或起火。

## 現況與問題

| 問題 | 位置 | 後果 |
|---|---|---|
| 基礎重心 `center_of_mass_offset` 低於輪軸 | [chassis.gd](../../rv/chassis.gd) | 約需 3 g 側向力才翻，物理上翻不了 |
| 沒有設定 `wheel_roll_influence` | [chassis.gd](../../rv/chassis.gd) `_create_wheel_at` | 側向力幾乎不產生側傾 |
| `steering_lateral_acceleration` 把轉向鎖在低側向加速度 | [chassis.gd](../../rv/chassis.gd) `_physics_process` | 永遠到不了抓地極限 |
| 輪胎只有單一 `wheel_friction_slip`，沒有滑移模型與路面差異 | [tire_dynamics.gd](../../rv/tire_dynamics.gd) | 手感像軌道車 |
| 驅動力只是油門乘上檔速比例 | [chassis.gd](../../rv/chassis.gd) | 沒有引擎煞車與扭力變化 |
| 車殼不撞地：Chassis 碰撞只有底板、大樑、裙板；面板是凍結的 static 子剛體 | [chassis.tscn](../../rv/chassis.tscn)、[rv_panel.gd](../../equipment/rv_panel.gd) | 翻過去車廂會沉進地裡 |
| 所有撞擊都進 `Chassis.take_damage()` 扣引擎 | [chassis.gd](../../rv/chassis.gd)、[vehicle_impact.gd](../../rv/vehicle_impact.gd) | 面板、輪胎、設備、玩家都不受影響 |
| 下車點用車身本地座標加地面法線尋找 | [driver_seat.gd](../../equipment/driver_seat.gd) `_find_clear_exit_position` | 翻車時找不到，玩家困在座位 |
| 沒有扶正手段 | — | 翻車即卡死 |

## 設計

### 1. 車殼碰撞與翻車狀態

新增 [hull_collision.gd](../../rv/hull_collision.gd)，由 `StructureSlots` 的槽位清單產生車殼碰撞形狀，掛在 Chassis 本體。

- 依 [structure_slots.gd](../../rv/structure_slots.gd) 的槽位建立形狀。每個槽位沿用面板的盒形碰撞幾何，保留原有窗框、門框和梯口。
- 形狀比面板薄並置中。射線和角色從內外兩側都先碰到面板，怪物攻擊目標與玩家站立判定不變。
- 面板被毀時關閉對應形狀。門板開啟時只關閉對應門扇形狀，保留門框。屋頂梯口沿用固定開口。
- 保留「形狀索引 → 槽位」對照表，供車損分配使用。
- 加形狀會改變轉動慣量，完成後核對並視需要明確設定。

新增翻車狀態，由車身上方向與世界上方向的夾角決定：正常、側躺、倒置。

- 側躺或倒置時引擎熄火，`engine_start_reason()` 回報原因。
- 翻車離座以世界上方向掃描車外地面，再用直立玩家的碰撞體驗證空間。
- 狀態由姿態推導，不進存檔。

### 2. 操控模型

**先導驗證（動工第一步）**。混合式有兩個前提：

1. 把 `wheel_friction_slip` 設為 0 後，`VehicleBody3D` 是否只留懸吊、不再施加輪胎摩擦。
2. `VehicleWheel3D` 不公開懸吊力，輪胎載重要從接觸點幾何重算，精度是否夠用。

**階段 0 結果**。在本機 Godot 4.7.2 的 Jolt 物理測試中，四輪關閉原廠摩擦、引擎力及煞車後，穩態載重估算為車重的 1.000002 倍。滑行 35 個物理幀前後的水平速度皆為 (3, -8) m/s。保留 `VehicleWheel3D` 懸吊，以原生射線長度和阻尼公式重算瞬時載重，再由傳動與輪胎模型施力。原廠原始碼中的零側向衝量分支仍可能保留縱向力，因此三項都在輪上停用。

**調校資料**。所有調校值放進新資源 `RVHandlingProfile`（`rv/handling_profile.gd` 與 `.tres`）。測試一律讀這份資源，不抄數值。

**輪胎**（新增 `rv/tire_model.gd`，純函式，可無頭測試）：

- 側向力依滑移角先升到峰值再下降。
- 縱向力依滑移率計算，與側向力共用抓地額度。重煞加轉向會推頭，後輪給油過頭會甩尾。
- 抓地力隨輪胎載重變化，載重轉移會影響前後、左右輪。
- 路面係數分柏油、路肩、泥草地，由 [world_field.gd](../../world/terrain/world_field.gd) 的 `road_query` 判斷。
- 既有的輪胎耐久與爆胎併入同一套係數，取代 `TireDynamics` 內的常數。

**重心與翻車門檻**：

- 基礎重心拉高到約地板高度。空車的靜態翻覆門檻略高於柏油抓地峰值。
- 結果是平地柏油穩態過彎會先滑。
- 會翻的情況：高速急打造成的側傾過衝、連續左右甩、側坡、側滑時絆到路肩或石頭、車頂載重過高。
- `update_load()` 已把設備與面板重量算進重心，車頂裝什麼會直接影響翻車風險，不需另寫規則。

**懸吊**：調軟、加防傾桿與行程末端緩衝。要看得到側傾與煞車點頭。

**轉向**：移除側向加速度上限。高速滿舵對應抓地極限附近的滑移角。保留依速度變化的方向盤反應速度，讓鍵盤操作仍可控。

**傳動**（新增 `rv/drivetrain.gd`）：

- 引擎扭力曲線乘檔位比，沿用現有四檔手排與倒檔。
- 收油有引擎煞車。轉速由輪速與檔位推算，取代目前僅供顯示的估算。
- 後輪驅動、開放式差速器。單輪離地時會空轉。
- 煞車前重後輕，可鎖死，無 ABS。手煞只作用後輪。
- 引擎耐久對輸出的影響沿用現有規則。

`chassis.gd` 的輸入處理與驅動計算移到上述新檔，其他系統使用的介面不變。

### 3. 車損

新增 `rv/crash_damage.gd`，依接觸到的車殼形狀分配傷害。撞擊能量仍由 `VehicleImpact` 以速度損失計算。

| 接觸位置 | 受損對象 |
|---|---|
| 車頭 | 前牆與引擎分攤 |
| 側面、車頂、車尾 | 接觸到的面板 |
| 底盤（底板、大樑、裙板） | 引擎，沿用現行規則 |
| 車輪重落地或側向撞擊 | 輪胎耐久，超過門檻爆胎 |
| 翻倒後在地上滑行 | 接地面板依滑行速度持續磨損 |

- 面板的磨損、碎裂與毀壞表現沿用既有系統。
- 面板被毀時，掛在上面的設備照既有規則掉落。
- 樹木與怪物的讓路規則不變。

### 4. 玩家受傷

輸入是玩家所在位置的車廂速度變化，取自同一次撞擊事件。門檻放在 `RVHandlingProfile`，下表是初始目標值。

| 速度變化 | 後果 |
|---|---|
| 低於 4 m/s | 無 |
| 4–8 m/s | 輕傷扣血 |
| 8–14 m/s | 重傷，短暫視線變暗與耳鳴 |
| 10 m/s 以上 | 開始有機率斷一肢，機率隨速度變化上升 |
| 14 m/s 以上 | 可能致死 |

- 坐在駕駛座時傷害減半，斷肢機率較低。
- 站在車內或車頂時，解除 `RVSupport` 並帶著原速度被甩出，再吃碰撞傷害。
- 玩家新增 `apply_crash_hit()`，比照 `apply_explosion_hit()`：一次事件只決定一次受傷冷卻與斷肢。
- 斷肢走既有的 `sever_part`。斷手後不能開車等規則照舊。
- 斷肢抽選可用固定種子重現。
- 暈眩效果只用螢幕空間與音效，不放任何世界內文字。

#### 主動跳車

[駕駛座](../../equipment/driver_seat.gd)沿用短按 `interact` 離座。[玩家移動](../../player/player.gd)已有繼承車速的邏輯，可作為跳車的起點。

- 玩家實際離開行駛中的 RV 時，開始追蹤落地或撞擊。適用於離座時直接落到車外，或離座後自行跳下、走下車身。離座後仍站在車內或車頂時，等玩家脫離車身支撐再開始追蹤。翻倒後使用第 1 節的逃生離座流程。
- 攀在 RV 梯上時，沿用現有的跳躍鍵脫離，接著判定落地或撞擊。
- 離開時繼承離車點的車身線速度與旋轉速度。玩家帶著慣性落地或撞上障礙物。水平慣性在落地後逐步消退，高速落地可短暫滑行或踉蹌。
- 以接觸前相對於地面或障礙物的速度判定嚴重度。撞牆看朝向牆面的速度，落地同時考慮下墜速度與沿地面滑行的速度。低速、低落差跳車可無傷，高速跳上平路仍可能受傷。扣血與短暫失衡的門檻獨立放在 `RVHandlingProfile`，首版只在這次跳車的移動中判定。
- 每次跳車在首次達到受傷門檻的接觸結算一次，之後的擦地或彈跳沿用該結果。同一接觸若也是車禍傷害的來源，只結算一次。斷肢仍由車禍受傷規則處理。

### 5. 翻車脫困：千斤頂

新增可搬運物品 Recovery Jack。

- 放在翻倒車身貼地的那一側，長按互動搖起。
- 對車身接觸點施加真實的力。過了平衡點後車自己倒回去，落地會有輕微衝擊。
- 倒置需要兩段：車頂到側躺，側躺到正立。
- 地形不利時可能頂不過去，需要換邊或換位置。
- 新增配方並登記到 [recipe_catalog.gd](../../equipment/recipe_catalog.gd) 與 [save_scene_catalog.gd](../../core/save_scene_catalog.gd)。
- 模型使用專案既有工業材質與手工幾何，含底座、打孔導軌、抬升頭與把手。遊戲內已擷取固定相機畫面檢視。

### 6. 回饋

- 音效：輪胎尖叫、車殼刮地、撞擊，加在 [vehicle_audio.gd](../../rv/vehicle_audio.gd)。
- 儀表：[instrument_cluster.gd](../../rv/instrument_cluster.gd) 新增傾斜警示燈。這是儀表，符合世界內文字規則。
- 鏡頭：座位鏡頭是車身子節點，本來就跟著滾。另加小幅頭部慣性。

## 施工階段

變更集中在 `codex/rv-handling-rollover`。共用的調校資源、車殼碰撞、乘員傷害與救援實作隨同相關回歸修正提交。試玩場和驗收紀錄一併交付。

| 階段 | 內容 | 完成判準 |
|---|---|---|
| 0 | 先導驗證：零摩擦懸吊與載重估算 | 決定車輪維持 `VehicleWheel3D` 或改自製射線，結果寫進本計畫 |
| 1 | 車殼碰撞、翻車狀態、離座、車損分配 | 預先翻倒的 RV 停在車殼上；車頂落地扣車頂面板；玩家能離座 |
| 2 | 輪胎、傳動、懸吊、重心、轉向 | 平地柏油穩態過彎不翻；側坡與絆翻會翻；煞車與加速測試更新後通過 |
| 3 | 玩家受傷與跳車 | 門檻、座位減傷、甩飛、斷肢（固定種子）有自動測試；低速跳車無傷，高速落地或撞牆只結算一次 |
| 4 | 千斤頂裝備與模型 | 側躺與倒置都能扶正；物品可存讀檔、可製作 |
| 5 | 音效、儀表、鏡頭、調校、文件 | 使用者完成手感驗收；文件更新 |

## 存檔影響

- 千斤頂已登記為可保存 Item。翻車姿態沿用車輛 Transform，沒有新增車輛快照欄位。
- 教學第二室增加一支千斤頂，Checkpoint 提升到 v8 並寫入新路徑。車輛快照保留 v6。

## 風險與未驗證事項

- 翻車時工作台仍受實際出料空間限制。首支千斤頂可從道具倉庫或教學補給取得，補製配方使用 8 個 Metal Parts。
- 接近側坡、路肩及重心偏移時的極限，以及撞擊音效、耳鳴與鏡頭手感需在試玩場驗收。

## 不在本計畫範圍

絞盤、一般乘客座位、天氣對抓地的影響、車身變形網格、漏油與起火、車輪脫落、怪物在翻倒車輛上的新行為。
