## 接續開發

2026-09-19：完成 [POI 共用製作規範](../guides/poi-authoring.md) 及室外資產定義目錄，分流副本入口／直接探索型；加油站仍為獨立測試資產。房型表、多樓層、正式場址自動安置與新保存資料仍待接續。

1. 先核對根目錄現況、相關程式與本計畫的未勾選項目；混合「已完成基礎＋尚未完成擴充」的工作應拆開追蹤。
2. 依原計畫的優先順序選工作。POI 保留先確認三維接口／樓梯原型的方向；RV 駕駛計畫保留先處理階段 1、2 的方向，跨計畫優先權尚未排定。
3. 完成後記錄自動測試、實機觀察與未驗證範圍，再更新計畫狀態及 GDD／architecture。歷史報告不因新程式而改寫為新結果。

勾選只代表該項列出的範圍；「已實作」「已有驗收紀錄」「全情境驗收完成」不可互換。存檔版本（目前 v3）與地形生成版本（新世界 v4）是不同欄位。
