## 待人工驗收

已經實作、自動測試涵蓋不到、還沒有人實際玩過確認的項目。驗收通過就刪掉該列；發現問題就改成待辦或開計畫。

| 項目 | 要看什麼 |
|---|---|
| RV 擬真操控 | 見[計畫](rv-handling-rollover.md)的未結項目 |
| 製造台復活 | 試玩 F7，確認眼睛閉合與睜開、吸氣音量，以及移動中車內的觀看舒適度 |
| 受傷暈眩 | 手動重撞、近爆或連續受傷時，確認全黑長度、復焦、耳鳴與逃生操作手感 |
| 地形階段 1–3 | 實際渲染、山路急彎與升降、橋梁輪驅，見[計畫](terrain-overhaul.md) |
| 教學基地 | 階段四的建築美術 |
| 公路隨機生成 | 手動輪驅穿越新分布、追擊、玩家拾取、車撞油桶爆炸 |
| 巨型避難所 | 完整自由遊玩與最終美術 |
| 軍事地堡 | 長局收益與遭遇節奏、自由遊玩、效能 |
| 駕駛體驗 | 一般操作、UI 瞄準、音效聽感 |
| RV 操作回饋與撞擊錄音 | 在 [RV 音效試點](../../tests/playgrounds/rv_audio_playground.tscn) 用數字鍵與 Z／X／C／V／B／N 逐一試聽：錄音是否符合動作、音量是否一致、車內外是否合理 |
| Slender Speaker 遠距預警 | 在[展示場景](../../world/demo_world.tscn) 駛離車庫後，確認能在看見巨人前辨認旋律與方向，並檢查引擎運轉及車門關閉時的音量 |
| 短波收音機 | 實際遊玩時的人聲能否聽清、廣播間隔與車內音量 |
| 長途經濟 | 油電與材料的長途平衡；極端載重、外掛力矩與怪物群 |
| 大型物品與攀梯 | 手持大型物品時拒絕攀梯、攀梯中取得大型物品的脫離 |
| 效能 | 串流載入與群怪的幀時間，見[架構重構](architecture-refactor.md#執行效能)的量測清單 |
