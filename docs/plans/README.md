## 待人工驗收

已經實作、自動測試涵蓋不到、還沒有人實際玩過確認的項目。驗收通過就刪掉該列；發現問題就改成待辦或開計畫。

| 項目 | 要看什麼 |
|---|---|
| RV 擬真操控 | 見[計畫](rv-handling-rollover.md)的未結項目 |
| 製造台復活 | 試玩 F7，確認眼睛閉合與睜開，以及移動中車內的觀看舒適度 |
| 受傷暈眩 | 手動重撞、近爆或連續受傷時，確認全黑長度、復焦、耳鳴與逃生操作手感 |
| 地形階段 1–3 | 實際渲染、山路急彎與升降、橋梁輪驅，見[計畫](terrain-overhaul.md) |
| 教學基地 | 階段四的建築美術 |
| 公路隨機生成 | 手動輪驅穿越新分布、追擊、玩家拾取、車撞油桶爆炸 |
| 巨型避難所 | 完整自由遊玩與最終美術 |
| [Mile End 廢棄小站](../../tests/playgrounds/mile_end_playground.tscn) | 開 RV 停靠、徒步搜店再搬油回車，確認油桶人露出的位置與時機。預設種子 25 可遇敵。 |
| 軍事地堡 | 長局收益與遭遇節奏、自由遊玩、效能 |
| 駕駛體驗 | 一般操作、UI 瞄準、音效聽感 |
| 怪物聲音 | 在[怪物音效試聽場](../../tests/playgrounds/monster_audio_playground.tscn)逐一切情境：Raker 的腳步、低吼與喀噠是否在中距離就聽得出來，橫掃與抓咬前的預備聲是否來得及閃；油桶人在 8 m 外是否完全無聲、起身與跑動是否好認、倒數嘶聲是否夠急；黑影 4 m 內的呼吸、尖叫與腳步；白影不回頭時能否聽出它在身後、越近越清楚；Slender Speaker 關掉喇叭音樂後，遠處巡邏和衝過來時的腳步是否沉重好認。在 [RV 音效試聽場](../../tests/playgrounds/rv_audio_playground.tscn) 的 Driver seat 拉轉時播 `slender_speaker/step` 與 `apparitions/white_appear`，確認車內仍聽得到。實際遊戲中再聽一次地堡的 Raker 與霧中的巨人腳步 |
| 新式測試場 | 在 [RV 音效試聽場](../../tests/playgrounds/rv_audio_playground.tscn) 用正式操作走動、開門、入座拉轉，並用 Esc 的 Playground 頁切情境與播放：確認比舊的快捷鍵版本好用，三個情境的起點正確 |
| Slender Speaker 遠距預警 | 在[喇叭試聽場景](../../tests/playgrounds/slender_speaker_audio_playground.tscn)從 900 m 開近：遠處悶、帶回音、方向較模糊，靠近時持續變響變清楚，最後幾十公尺最有壓迫感；近距離限幅是否刺耳，回音是否太濕；關門與開門的差別。在正式世界確認關門行駛時仍能在看見巨人前聽出方向 |
| 短波收音機 | 實際遊玩時的人聲能否聽清、廣播間隔與車內音量 |
| 長途經濟 | 油電與材料的長途平衡；極端載重、外掛力矩與怪物群 |
| 大型物品與攀梯 | 手持大型物品時拒絕攀梯、攀梯中取得大型物品的脫離 |
| 效能 | 串流載入與群怪的幀時間，見[架構重構](architecture-refactor.md#執行效能)的量測清單 |
