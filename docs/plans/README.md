## 建議接續順序

在擴充內容前，先收斂 [架構審查 A01–A04](../report/ApocalypseRV_Architecture_Audit_2026-09-22.md) 的設備依附、UI 物理、回程 actor 清理與 POI 離場取消。這些已重現問題尚未修正；導航生命週期與群怪效能另列待驗證。舊檔清理依同報告分批進行，保留存檔遷移與歷史紀錄。

| 順序 | 可交付範圍 | 完成判準 |
|---|---|---|
| 1：駕駛與安裝問題收斂 | 複查 todo 的方向盤左右、電池槽／設備預設方向、加油孔尺寸與角落閃爍；駕駛調校與鏡面已有量測，接續一般操作驗收 | 回報有重現／結案證據；實作與受控回放不代替自由遊玩手感 |
| 2：隨機軍事地堡 | 依已確認的可擴充房型計畫完成主體及基本外觀 | 1000 seeds、真實通行、保存、主世界與實機觀察 |
| 3：探索與收益 | 地堡主體穩定後再設計搜刮、撤退、物資及遭遇 | 本輪不製作目標／捷徑／收益配置 |
| 4：操作回饋與夜間流程 | 駕駛階段 2／3 已實作，階段 4 受控回放通過；補一般 UI 操作、聽感與夜間更多視角 | 白天／夜間人工完整出車、維修、整補再出發；與自動結果分開記錄 |
| 持續驗收 | RV-06 長途油電／材料平衡，POI-07 載入／重返／記憶體量測，群體敵人與物理專項 | 保留真實油耗與工作成本；結果區分自動回歸、實機觀察、量測與未測範圍 |

若下一輪優先增加可玩的內容，可直接選第 2 項；不需把音效與全部照明當作 POI 前置條件。

## todo 核對與仍待收斂事項

根目錄 [todo](../../todo) 保留每個原始項目與順序，新增完成／部分／待複查標記；[todo_prompt](../../todo_prompt) 保留 POI 三種類型與未來模型接入方向。確定完成的引擎維修、底盤模型重作、車門窗戶、車撞怪物傷害、戶外遮蔽與互動結果提示，不再列為從零開發工作。

- 「移除發電機」尚未實作，與目前能源設計不同；下一批若選此項，須先定義替代充電入口、耗油、空電救援及舊存檔設備處理。
- 「撞車受損」與「撞車車損」是同一待辦；怪物被撞扣血已完成，不代表 RV 撞牆會扣耐久。碰撞傷害需定義受損對象、門檻與冷卻；外掛設備仍是獨立凍結剛體，力矩傳遞另需實測。
- 拿重物禁止攀爬、三片屋頂、一般座位、出生點建築、丟物手感、粉碎機傷人、指令系統尚未完成；死亡／布娃娃／回收復活保留原「先不做」方向。
- 天氣視聽已完成；淋濕、體溫、感知、抓地、雷電、積水及濕地材質未實作，雨霧呈現參數也尚未統一成單一設定資源。
- 怪物已能破門／拆頂，車內主動拆設備或拆出路線未做；敵人群體與遭遇節奏不因既有近戰修正而結案。

## 接續工作方式

1. 先核對根目錄現況、相關程式與本計畫的未勾選項目；混合「已完成基礎＋尚未完成擴充」的工作應拆開追蹤。
2. 依上方建議選一批，先界定該批驗收範圍。POI 接續 v2 自由探索與收益驗收，RV 接續一般操作驗收；未選中的擴充繼續留待辦。
3. 完成後記錄自動測試、實機觀察與未驗證範圍，再更新計畫狀態及 GDD／architecture。歷史報告不因新程式而改寫為新結果。

勾選只代表該項列出的範圍；「已實作」「已有驗收紀錄」「全情境驗收完成」不可互換。存檔版本（目前 v3）與地形生成版本（新世界 v5）是不同欄位；v2–v4 舊世界仍保留原生成／串流規則。v5 回程不等於全世界所有散落物永久保存。
