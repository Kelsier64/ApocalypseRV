## 第七關契約

`TutorialService` 第 7 關完整停車區為 X ±3.5 m、Z −108～−80 m。RV 完整停入、熄火、手煞車、玩家處於 `NORMAL` 並離座且互動結束才配置一次：`slot_left_0.HEALTH` 設為 max−60；保留原引擎 ID，且其 `HEALTH` 設為 max−150；`wheel_0` 爆胎。發一包引擎維修包與指定 ID 健康備胎；一般物品位於 x −7/−8.5、y .12/.03、z −94；車內直接保留至少兩份金屬。故障配置與物理穩定後才建入口快照，保存配置旗標／原引擎與輪胎 ID。

- 修牆用 `rvctl` Structure，实际施工完成且滿耐久；現場 H 不適用車體牆片。
- 維修蓋完全開啟，手持引擎維修包，H 持續三秒；原引擎成功維修交易且消耗一包才算，換健康引擎不算。
- 空手對指定輪槽長 E 拆胎，拾取指定備胎，空槽長 E 安裝；修補原胎、原胎拆裝不算。
- 自由順序，同時要求成功紀錄與當前可用狀態，出發前收妥維修蓋。
- 只有實際側牆修復、消耗維修包的原引擎修復交易、拆除原輪並安裝指定備胎且目前三項均健康，才完成本關。讀檔、重看終端、返回區域不重複破壞／發物資；重試恢復已配置入口快照。取消不收費，替代零件或操作不計。

## 共用契約

RV 只有一台獨立教學終端，繼承 Item，使用正常拾取、背包、丟棄、固定／拆卸、支撐掉落、供電、回收及保存。加入 ItemDefinition、可信場景目錄、狀態驗證、回收與背包圖示；不能授權 `rvctl` 車體施工。進度由 StartRun 下控制器持有，說明書解鎖放版本化 Item 狀態，搬運／換車／跨場景保留 ID、所有權與解鎖。

英文終端集中顯示條件、完成狀態、步驟和按鍵，只開啟時顯示，不建教學 HUD。第一關以本關條件頁成功顯示為準；靠近、拒絕互動、讀檔初始化、開 rvctl 不算。全通關同物品轉可搜尋說明書；略過也解鎖但標記 skipped。海報只寫民防／末日生存世界觀及常識，沒有按鍵、過關清單；第一張明確指向車上教學終端。

教學準備期維持 `preparing`，停止時間／天氣／敵人，直到第九關按下有效啟程按鈕才開始正式旅程。新局燃油 40，準備期燃油保底 10、已裝有效電池電量保底 20；空槽不供電、不補遺失設備，保底不觸發換電池／加油判定。完成或略過時解鎖內門並取得同一持久 ID 終端的說明書；略過標記 `skipped`、清除重試入口，不生成物品、不直接加油或修車，且仍留在準備期，準備期燃油／電量保底繼續生效，直到按下啟程按鈕。正式旅程中 Restart Stage／Skip Tutorial 停用。出口受阻重開，整車及玩家離場才永久封門。新建築靜態網格預算 20 萬三角面。

用持久 ID、指定槽位、成功交易事件判定查看、交換、回收、出料、維修、輪胎拆裝，失敗／取消／預覽不計。Esc 提供 Restart Stage／Skip Tutorial，不依賴終端存在。抽出 `capture_world()`／`load_snapshot()`，隔離世界驗證後才替換；失敗保留當前世界。重試恢復當關完整入口、不覆寫手動檔，快照随存檔且禁止遞迴嵌套；現況與入口各自驗證 ID／所有權。

新局生成 v11，v7–v10 使用原基地，Checkpoint 外層 v5、StartRun v1。教學狀態為版本化資料；教學資料 v3、維修服務資料 v1。Restart Stage 還原當關狀態，不覆寫手動存檔；正式旅程開始後不可重試。舊教學 ACTIVE v1/v2 升級為 v3；COMPLETED 存檔保留舊來源版本，不偽造第 7–9 關完成證明。第 7 關保存已配置入口快照與故障 ID；階段五補齊第 8–9 關、說明書與略過流程。說明書 Item 狀態 v1，搬運、丟棄、收納至其他 RV 或 POI 保存資料皆保留解鎖結果及完成／略過紀錄；終端不具 RV 建造權限。

## 第八、九關及啟程契約

第八關在指定 RV 實際轉入第六關工作台製造的汽油罐，並取得回傳空罐才完成；滿油拒絕時不消耗汽油罐。第九關要求第七關原引擎、側牆、指定備胎均修復且目前可用，第八關已加油，維修蓋關閉，RV 停穩／手煞車／熄火後離座按啟程按鈕。按鈕有效才解除時間、天氣與敵人暫停；玩家及整台指定 RV 離開出口後封門，出口路徑受阻便重開。完成流程把原終端解鎖成含 Completed 紀錄的可搜尋說明書。

說明書有九課及按鍵參考，英文多詞搜尋需全部符合同一課；同一終端在持有、背包、RV／POI 存檔等狀態保留解鎖與結果。Esc → Skip Tutorial 可提前解鎖同一本說明書並記錄 Skipped，不替玩家造物品或修車，也不開始旅程。只有仍在 preparing 時可 Restart Stage 或 Skip；啟程按鈕接受後兩者都停用。完整驗收前維持既定場地幾何與美術，不把階段六納入本次實作。
