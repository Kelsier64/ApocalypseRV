## 第七關契約

RV 完整停入、熄火、手煞車、玩家離座且互動結束才配置一次：指定側牆耐久 max−60，保留原引擎 ID 並設 max−150，指定左前輪爆胎。發一包引擎維修包與固定 ID 健康備胎，車內金屬補足至少兩份。故障配置與物理穩定後才建入口快照，保存配置旗標／原引擎與輪胎 ID。

- 修牆用 `rvctl` Structure，实际施工完成且滿耐久；現場 H 不適用車體牆片。
- 維修蓋完全開啟，手持引擎維修包，H 持續三秒；原引擎成功維修交易且消耗一包才算，換健康引擎不算。
- 空手對指定輪槽長 E 拆胎，拾取指定備胎，空槽長 E 安裝；修補原胎、原胎拆裝不算。
- 自由順序，同時要求成功紀錄與當前可用狀態，出發前收妥維修蓋。
- 讀檔、重看終端、返回區域不重複破壞／發物資；重試恢復已配置入口快照。

## 共用契約

RV 只有一台獨立教學終端，繼承 Item，使用正常拾取、背包、丟棄、固定／拆卸、支撐掉落、供電、回收及保存。加入 ItemDefinition、可信場景目錄、狀態驗證、回收與背包圖示；不能授權 `rvctl` 車體施工。進度由 StartRun 下控制器持有，說明書解鎖放版本化 Item 狀態，搬運／換車／跨場景保留 ID、所有權與解鎖。

英文終端集中顯示條件、完成狀態、步驟和按鍵，只開啟時顯示，不建教學 HUD。第一關以本關條件頁成功顯示為準；靠近、拒絕互動、讀檔初始化、開 rvctl 不算。全通關同物品轉可搜尋說明書；略過也解鎖但標記 skipped。海報只寫民防／末日生存世界觀及常識，沒有按鍵、過關清單；第一張明確指向車上教學終端。

最終教學期间維持 preparing，停止時間／天氣／敵人，正式啟程才解除。新局燃油 40，準備期燃油保底 10、已裝有效電池電量保底 20；空槽不供電、不補遺失設備，保底不觸發換電池／加油判定。解鎖內門維持開啟；出口受阻重開，整車及玩家離場才永久封門。新建築靜態網格預算 20 萬三角面。

用持久 ID、指定槽位、成功交易事件判定查看、交換、回收、出料、維修、輪胎拆裝，失敗／取消／預覽不計。Esc 提供 Restart Stage／Skip Tutorial，不依賴終端存在。抽出 `capture_world()`／`load_snapshot()`，隔離世界驗證後才替換；失敗保留當前世界。重試恢復當關完整入口、不覆寫手動檔，快照随存檔且禁止遞迴嵌套；現況與入口各自驗證 ID／所有權。

新局生成 v11，v7–v10 使用原基地，Checkpoint 外層 v5；後續新增版本化教學狀態與驗證，不改寫舊存檔。階段一目前只加入 StartRun v1 的選填八內門 bool 狀態；尚沒有教學進度或重試快照。
