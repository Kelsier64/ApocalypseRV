## 場址與建築

- 兩室串接：第一室長 20 m，第二室長 40 m，合計 60 m；寬度暫沿用既有 40 m。
- 出口朝向公路；第一室為封閉接待室，第二室為倉儲維修區。若保留目前出口局部 Z=14，第一室為 Z=-46～-26，第二室為 Z=-26～14。
- 第一室除固定建築及照明外，只放一台固定於牆面底座的教學終端和一張海報，沒有 RV、工作設備、補給、武器或其他可拾取物品。隔牆遮住第二室，開門後才看見壞車。
- 第二室保留中央至少 8 m 車道；出口淨空至少 7×5 m。RV 停在中央維修位置，車頭、兩側轮槽、車門及出料區各留操作空間，設備與材料架置於兩側。
- 沿用舊避難所牆面材質、按鈕與門模型；重新縮排牆體、屋頂、梁柱、門框、管線、照明及設備支撐，移用符合新尺寸的現有構件。
- 本次不設模型面數上限；美術完整度優先，效能優化依使用者要求留到之後。
- 新局建議採獨立 v12 場址與新版教學狀態；v11 九區及 v7–v10 避難所保留原布局和讀檔分流，不把舊九關進度直接映射成新兩室進度。

## 第一室：初始化與帶走終端

1. 玩家空背包出生，海報以民防宣導口吻引導查看牆上的終端。海報沒有按鍵或過關清單。
2. 開啟指定終端時，首先顯示純文字 Linux TTY 風格的啟動提示。玩家按 Enter 後開始捲動啟動日誌；核心、設備、檔案系統與教學服務全部準備完成後，才記錄初始化完成。靠近、單純開啟介面、尚未跑完的日誌或讀檔不算。
3. 啟動完成後自動切換到既有教學終端 TUI 的 Conditions 頁，顯示英文條件：`Take this terminal with you.`，並說明如何關閉介面、拆下終端。原固定座此時解除鎖定；完成初始化前不能拆下。
4. 必須從原固定座拆下同一持久 ID 的終端，成功放入玩家背包後，中間門才開啟並保持開啟。破壞掉落、取消、背包轉移失敗或其他終端不算。
5. 玩家實際進入第二室後，手上的終端切換為修復車輛指南。

## 第二室：選做的車輛恢復指南

房間內提供原 RV、一台可搬運分解機、一台可搬運製造台、8 件廢料、2 個油桶、一顆健康備胎、一顆滿電備用電池及 2 包引擎維修包，各有持久 ID。物資分散在兩側貨架下層、棧板區與側邊通道；高層封箱為固定倉儲布景。中央車道保持淨空。

RV 新局為兩片牆板各損失 60 耐久、指定左前輪爆胎、原引擎耐久 0、已安裝電池電量 0，以及中段車頂 `roof_1` 完全毀壞。地板、設備支撐、維修蓋和操作必要門片保持可用。故障只配置一次；已有演練配置的舊存檔保留當前狀態，不重新損壞或補發物資。

下列項目都是新手操作參考，不是門禁條件。成功紀錄可在任意順序累積，取消、預覽及失敗不計入；建議步驟及重試不強迫玩家照順序操作。

| 參考 | 終端引導及實際紀錄 |
|---|---|
| 換電池 | 使用原生插槽交換，恢復實際供電；不自動補充電量。 |
| 引擎 | 維修蓋全開後，手持維修包持續 H 三秒，原生交易消耗一包、恢復 150 耐久；一包即可恢復運轉，第二包可改善耐久。 |
| 搬上設備 | 指定分解機與製造台固定在同一台 RV；可先固定再恢復供電。車體施工仍使用既有 rvctl，教學終端只提供指南。 |
| 回收 | 原指定材料及新增廢料完成處理，材料真正入庫；等待中不算。 |
| 製造 | 汽油罐實際出料並拾取；加入佇列不算。 |
| 車體 | 用 rvctl 修牆或重建 `roof_1`；中段原型為艙口屋頂，須保留梯子所需空間。亦可拆下原爆胎並裝上備胎。 |
| 加油 | 透過原生加油口真正轉入燃油，取得空罐。 |
| 離場 | 原 RV 朝出口進入感應區即開門，不檢查上述任何紀錄或當前修復程度；普通駕駛仍受實際車況影響。 |

全部 8 件廢料與 2 個油桶保證 28 Metal Parts、20 Unrefined Fuel。汽油配方需 2 Metal Parts＋5 Unrefined Fuel；兩片牆修復共需 4 Metal Parts，中段屋頂重建需 6 Metal Parts，完成一次完整示範仍有 16 Metal Parts 餘裕。充電電池、兩包維修包及備胎由架位提供。

RV 預裝空電池、插槽、rvctl 平板及加油口。新兩室局燃油從 0 開始，不套用燃油或電量保底，也不補空槽或遺失設備。玩家可換充電備用電池，或在引擎及燃油恢復後使用既有引擎充電系統。

新版 RV 初始不固定分解機或製造台，兩台教學設備都在第二室地面等候搬運；既有車內平板與教學終端仍是兩個用途不同的物品。

## 終端重新設計

- 保持 `TrainingTerminal extends Item`，完整保留拾取、背包、丟棄、固定、拆卸、回收及保存；移動與換車不改變原持久 ID。
- 終端具獨立內部供電，牆上沒有 RV 時可以初始化，拿在手上也能閱讀。固定至 RV 後可使用車輛供電；內部電量及說明書狀態採相容的版本化 Item 資料。
- 手持閱讀直接使用背包中的原物品資料與獨立閱讀介面，不額外生成第二個有所有權的終端實體，也不解除其他手持模型的服務限制。
- 流程為「TTY 啟動提示 → Enter → TTY 捲動啟動日誌 → 既有教學終端 TUI → 第一室帶走條件 → 第二室目前步驟／操作參考 → 離場後搜尋說明書」。啟動日誌完成前不顯示過關條件。
- 2026-10-15 介面修訂：只有初始化完成前的啟動提示及啟動日誌模擬 Linux 底層 TTY，採黑底、小尺寸白色等寬字、綠色 `[ OK ]` 狀態與閃爍方塊游標。這段畫面從左上開始輸出文字；保留自然空白，不使用大型標題、圖示、卡片、裝飾框、圖形按鈕或 CRT 掃描線。這些限制不套用到初始化後的既有 TUI。
- Enter 前只有系統／主控台資訊，並持續顯示明確的啟動提示 `Press ENTER to boot the system.` 及閃爍游標。等待玩家按 Enter 才開始啟動；按下後約 5～7 秒輸出多批核心時間戳、記憶體／裝置偵測、檔案系統掛載、服務啟動與本地教學資料讀取；文字自然換行並向上捲動，部分階段短暫停頓，無需玩家閱讀每一行。
- 就緒後以 `field-guide --resume` 作為最後一行啟動文字，隨即切換到[既有教學終端介面](../../equipment/training_terminal_ui.gd)。沿用原本的終端配色、文字框、F1–F4 分頁、焦點操作與說明書搜尋：Conditions、Steps、Controls、Manual；只調整兩室教學內容、獨立供電及手持閱讀所需的資料來源。第二室與離場後說明書也沿用這套 TUI，不改成連續 TTY 日誌。
- 重複 Enter 不會重啟或疊加日誌。Esc 可關閉閱讀介面，重新開啟接續本次啟動進度；成功初始化後不再重播完整啟動流程。啟動動畫不生成物品或觸發過關。
- [可操作的 TTY 啟動參考](../mockups/field-terminal-boot.html)只示範初始化前的提示與開機日誌；末尾純文字條件僅代表交接內容，不是初始化後介面的設計。正式教學畫面沿用既有 TUI；此原型不包含遊戲實作。
- 教學條件、步驟及按鍵只在開啟終端時顯示；關閉後沒有教學 HUD。海報只談世界觀、生存與安全常識。
- 完成離場後，同一終端變成可搜尋說明書；略過則保留 Skipped 紀錄。重試與略過仍可从 Esc 使用，終端遺失時也能復原。

## 感應門、正式遊戲與保存

- 移除新版手動啟程按鈕。第一室仍須帶走原終端；進入第二室後，指定 RV 朝出口進入提前感應區就開門，不檢查任務、引擎、燃油、電池、設備、車牆、輪胎或車頂的教學條件。玩家步行或其他物品不觸發。
- 感應區留足停車及開門距離，不要求車輛先撞到門。出口移動保持實際碰撞與受阻重開。
- 玩家及整台 RV，包含突出於車體之外的固定設備碰撞，完全通過出口後自動結束安全教學期，恢復時間、天氣與敵人，並解鎖說明書。無額外出發確認畫面。
- 清空門口後永久封閉；受阻會重開，不夾住返回門口的玩家或車輛。
- 保存 Enter 確認、原終端 ID／所有權、設備與材料進度、故障旗標、維修／換胎／加油交易及離場狀態。
- 【此相容條款已於 2026-10-21 退役】Checkpoint 外層保留 v5，新增相容的教學子狀態版本與課程類型；StartRun 的門數及場址分流分別接受 v11 的八道內門與 v12 的一道內門。
- 第二室建議步驟轉換後，在當前批次操作結束且世界安全時建立完整復原點；自由順序及額外回收不會使待建立的復原點失效，已建立的點不被後續操作覆蓋。重試不改寫手動存檔、不重發或重施故障。第一室仍保留原始入口／開機判定。載入驗證失敗保留當前世界。
