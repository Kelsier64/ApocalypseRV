# 能源、材料與製作

RV 靠三種資源運作：油、電與材料。油讓引擎轉，引擎給電池充電，電讓設備工作；材料從回收來，用在製作與維修。這份文件說明這個循環、拆解機、工作台與車載平板。物品的共用規則見 [items](items.md)，引擎、車殼與駕駛見 [rv](rv.md)。

以下的數值都是原型參數，油與電沒有對應到真實單位，長途的平衡還沒做。

## 規則與數值

### 資源怎麼流動

1. 搜刮來的物品丟進拆解機，變成車上的材料。
2. 材料在工作台做成汽油罐、電池、輪胎、引擎與各種工具。
3. 汽油罐從加油口加進油箱。
4. 引擎運轉時耗油，並給電池充電。
5. 電池的電供設備工作：拆解、製作、車殼施工、車燈。

沒有任何一步會憑空補資源。沒電時拆解機與工作台停下來等；沒油時引擎熄火。

### 油料

- 油箱的容量與起始油量是 `Chassis.max_fuel`、`current_fuel`。
- 引擎運轉時耗油：怠速有固定的基本量（`fuel_idle_burn_per_second`），踩油門時依油門深度增加（`fuel_drive_burn_per_second`）。不同引擎再乘上自己的 `fuel_multiplier`，強化引擎比較耗油。熄火不耗油。
- 油用完時引擎自動熄火。
- **加油**：手上選取汽油罐，對著加油口按 E。每罐加 `Chassis.fuel_per_gas_can`，超出油箱容量的部分不保留。油箱全滿時不會用掉汽油罐。加油成功後手上的汽油罐變成空罐。
- 加油口只是加油的入口。拆掉、弄壞或多裝一個都不會改變油量與容量。

### 電力

- 電存在電池裡，電池裝在車上的電池插槽才供電。一輛車同時只有一顆電池在供電；沒有電池就沒有電，車上不會藏著看不見的電量。
- 電池分普通與大容量兩種（容量見 `props/battery.gd` 的 `initial_capacity` 與 `props/battery_large.tscn`）。每顆電池有自己的電量，帶著走、存進倉庫、存檔都跟著它。
- **待機耗電**：只要裝著電池，車子就持續耗電（`power_parked_drain_per_second`），熄火停車也一樣。目前沒有總電源開關。
- **工作耗電**：設備照進度付電。電不夠時工作暫停，不會有免費的進度。
- **車燈**：頭燈、煞車燈、倒車燈、車內燈條與引擎室工作燈亮著時各自耗電。
- 車上的設備依固定順序輪流處理：充電 → 待機耗電 → 各設備工作 → 車燈。平板上顯示的是實際的發電與負載速率。

### 換電池

- 手上選取電池，對著插槽按 E：把手上的電池裝上去，原本的電池回到背包的同一格。背包滿了也能交換。
- 長按 E 把電池取出來收進背包，這需要背包有空格。
- 車子要停下來才能換電池。
- 插槽被拆下、支撐掉了或損壞時，裡面的電池會掉在車旁。地上的電池不供電。

### 引擎充電

- 引擎運轉時給插槽裡的電池充電，行駛與原地怠速都算。熄火時不充電。
- 充電要額外耗油，而且是在引擎本身的油耗之外。發電與耗油的上限是 `VehicleEnergy.power_generation_per_second` 與 `fuel_consumption_per_second`。
- 平板的 Energy 頁可以調三個設定：是否充電、電量低於多少開始充（`recharge_below`）、保留多少油不拿來充電（`fuel_reserve`）。新車預設開啟充電。
- 電量降到門檻以下開始充電，充滿才停。油量降到保留量時停止額外充電，但引擎照樣怠速耗油。
- 電池沒電時仍然可以發動引擎，發動不需要電。
- 剛做好的電池是空的，要裝上車靠引擎充電。

### 材料

- 材料是車上的數字，不是物品：金屬零件、電子廢料、未精煉燃料、未知材料。名稱在 [item_names.gd](../../core/item_names.gd)。
- 所有材料合計不能超過 `Chassis.material_capacity`。容量屬於車，不靠設備提供。
- 拆解直接增加材料，製作與車殼施工直接扣除。平板只顯示數量，沒有把材料領出來變成物品的功能。
- 退還的材料（例如取消製作）可以讓庫存暫時超過容量；超過的部分照樣可以用。

### 拆解機

- **投入**：把散落的物品從上方丟進料斗，或手上拿著大型物品對著拆解機長按 E。油桶、輪胎、引擎與其他設備都能丟。
- **不收的東西**：固定住的物品、還在手上或預覽中的物品、已經被別台拆解機抓住的物品，以及拆解機自己和它的支撐。
- **排隊**：最多同時收 `queue_capacity` 件，一次只處理最前面那一件。每件的處理時間是 `crush_time`，處理期間持續耗電（`power_draw_per_second`）。
- **產出**：每種物品有自己的產出範圍（各物品場景或定義的 `scrap_yields`）。實際數量在處理完成時抽一次，之後不再重抽。沒有設定產出的物品給一份未知材料。
- **材料滿了**：處理完的物品留在機器裡等，產出數量已經定了，庫存有空間時才入庫。
- **停下來**：沒電時暫停並保留進度。拆解機被拆下或毀壞時，把還沒處理完的東西吐出來。

### 屍體與活體

- 怪物的屍體與玩家復活後留下的屍體都是大型物品，可以對著軀幹按 E 撿起來，丟進拆解機回收（產出見 `props/corpse.tscn`）。屍體不會隨時間消失。
- 活著的玩家或怪物掉進運轉中的拆解機料斗中心會被絞死：四肢先一段段被切離，最後才是軀幹，然後照一般屍體回收。切下來的肢體沒有材料。
- 只是擦到料斗邊緣、拆解機沒電、停用或已經排滿時，不會觸發。
- 各種怪物的差異：Raker 照一般死亡流程；油桶人照樣爆炸；Slender Speaker 不受影響。
- 玩家被絞死後保留背包，照一般流程復活，復活位置會避開有電的料斗。

### 工作台

- 在平板的 Crafting 頁選工作台與配方，加入佇列。佇列最多 `queue_capacity` 項。
- **加入佇列時**：材料立刻扣掉，並檢查電量夠不夠付完整份電費。
- **製作中**：電費照進度一點一點付。電不夠時暫停。
- **取消**：退回材料，已經花掉的電不退。工作台被拆下或毀壞時等同取消全部。
- **出料**：成品出現在工作台的出料位置，逐層列印成形。出料位置被擋住時，完成的工作留著等，清開後才出料，而且只出一次。
- 成品是一般的物品，帶著車子當時的速度。

### 配方

配方登錄在 `RecipeCatalog.all()`，每個配方的材料、時間與電費在各自的 `equipment/*_recipe.tres`：

- 油電：汽油罐、電池、大容量電池
- 車輛：輪胎、標準引擎、強化引擎、引擎維修包、救援千斤頂、床
- 工具：手電筒、電子指南針、野外終端
- 武器：手槍、手槍彈藥
- 玩家身體（復活用，見 [player](player.md)）

### 車載平板

- 長按 E 開啟固定在車上的平板。開啟時扣一點電（`power_cost_per_open`）；沒電時照樣能開，畫面顯示缺電警告。
- 平板開啟後直接進入 `rvctl` 管理介面，共五頁：Overview、Energy、Equipment、Crafting、Structure。F1–F5 切頁，Tab 與方向鍵移動焦點，Enter 啟用，也可以用滑鼠。Esc 關閉平板。
- 設備的工作進度不靠平板開著。
- 平板不能被摧毀。

### 終端指令

從管理介面退回指令列後可以輸入指令，有歷史紀錄與 Tab 補全。指令登錄在 `terminal_commands.gd` 的 `_init`：

| 指令 | 作用 |
|---|---|
| `help` | 列出指令或某個指令的用法 |
| `status` | 顯示這輛車的狀態 |
| `rvctl` | 回到管理介面 |
| `clear`、`exit` | 清除畫面、關閉平板 |
| `cheat` | 開關無限油、無限電、無限材料與飛行 |
| `time` | 讀取或立刻設定遊戲時間 |
| `weather` | 讀取或立刻設定天氣，選項見 [environment](environment.md) |

作弊的規則：

- 資源作弊只作用在這台平板所在的車上，重開平板仍然有效，讀檔或開新局後重設。
- 開啟後實際的數字不會補滿，只是不再扣。無限材料只免除數值材料；維修包、輪胎這類實體物品照樣會用掉。
- 飛行只作用在操作終端的玩家身上：不受重力與碰撞影響，不耗體力。入座、死亡、轉場與讀檔會結束飛行，飛行中不能存檔。
- `time` 與 `weather` 只是立刻改一次，之後照自然的規則推進。

## 實作契約

### 能源的結算

- `VehicleEnergy` 是油電結算的唯一入口，由 `Chassis` 每個物理步呼叫 `step`。順序固定：引擎油耗 → 充電 → 待機耗電 → 各設備的 `step_work` → 車燈。
- 設備依 `persistent_id` 排序後輪流工作，所以同一個狀態每次的結算順序都一樣。
- 電量只存在插槽裡的 `BatteryState`。`Chassis.current_power`、`max_power` 只是轉接，不另外存一份。
- 設備扣電一律走 `Item.consume_rv_power`，它先確認設備可以運作（固定、啟用、沒壞、接在車上）。
- 玩家在室內副本時，外面的車照常結算。

### 交易不能做到一半

- 加油：先把汽油罐換成空罐，確認背包裡真的多了那個空罐，才把油加進油箱。任何一步失敗就還原背包。
- 換電池：先確認新電池有效、舊電池有地方去，才交換。
- 製作：`craft_rejection_reason` 同時給平板顯示與實際交易使用，所以畫面說可以做，按下去就不會被另一套規則拒絕。
- 直接出料（`spawn_item`）先驗證場景、空間與完整成本才扣款；扣了電之後材料扣不成會把電退回。
- 回收：材料庫存接受了產出，才刪除投入的物品並發出 `recycle_committed`。

### 拆解機的投入物

- 物品進到料斗後由拆解機取得 `processing_owner`，同一件物品不會被兩台機器或玩家同時處理。
- 接手時記下物品原本的物理狀態，取消時原樣還回去。
- 產出數量寫在物品的 `recycle_result`，跟著物品狀態保存；讀檔或等庫存空間都不會重抽。
- 投入的動畫（翻轉、傾倒、壓皺、逐段切離）由 `scrapper_feed_motion.gd`、`scrapper_contact_feed.gd` 與 `scrapper_crush_effect.gd` 負責，只是表現。它們不產生材料，也沒有自己的碰撞。只有成功付了電的工作步才推進動畫。
- 活體掉進料斗時，在物理訊號裡只登記預留，延後一步才致死，避免在訊號中改動碰撞。預留不存檔。

### 屍體

`CorpseProp` 是帶著布娃娃骨架的大型物品，玩家與 Raker 共用。它的狀態（類型、缺失的部位、骨架姿勢）存在 `state.corpse`，跟著一般物品的流程進出背包、倉庫、副本與存檔。細節見 [props/corpse.gd](../../props/corpse.gd)。

### 工作台的佇列

- 每筆工作記下自己已付的材料與還沒付的電，取消時照這筆紀錄退款。無限材料開啟時加入的工作，取消時不退材料。
- 工作排到最前面時才決定成品的擺放方向，之後不再改；後來被擋住只會延後出料。
- 佇列隨設備狀態保存。

### 新增配方

1. 新增一份 `RecipeDefinition` 資源，加進 `RecipeCatalog.all()`。
2. 成品場景登錄到 `SaveSceneCatalog`，見 [saves](saves.md#場景白名單)。
3. 成品的回收產出寫在場景或定義的 `scrap_yields`。
