# Knowledge: Project Facts

## Environment and Tooling Facts
- Engine/runtime: Godot 4.6 (`project.godot` `config/features`).
- Physics engine: `Jolt Physics`.
- Rendering path: `gl_compatibility` on desktop/mobile render methods.
- Main runtime scene: `res://world/test_world.tscn`.
- Repo includes GDScript gameplay code and lightweight Python/offline scripts.

## Build/Test/Run Commands
- Run game scene from CLI:
  - `godot --path . res://world/test_world.tscn`
- Run headless Godot script:
  - `godot --headless -s <script.gd>`
- Run offline Python scripts (project rule: use `uv`):
  - `uv run main.py`
  - `uv run test_building_gen.py`
- Reality check: repository currently declares no formal build pipeline or automated test suite.

## Repo Workflow Constraints
- Use `uv` for Python entrypoints rather than raw `python`.
- For scene editing:
  - simple scene changes can be done directly in `.tscn`.
  - complex scene construction should use fresh generation scripts run headless.
  - editor-heavy tasks should prefer script + editor steps over fragile manual scene diffs.
- Gameplay contracts rely on group discovery (`player`, `monsters`, `rv`, `chassis`, `crafting_stations`) and duck typing (`has_method`, property existence checks).
- Equipment placement safety depends on collision exceptions across ancestor chains after reparenting.

## Glossary and Domain Terms
- **Chassis**: main drivable `VehicleBody3D` implementation in `rv/chassis.gd`.
- **Prop**: pickup rigid item (`props/interactable_item.gd`) that can be carried, dropped, and scrapped.
- **Equipment**: placeable rigid machine/device deriving from `equipment/equipment.gd`.
- **POI**: weighted point-of-interest package with building + loot + enemy config (`world/poi_config.gd`).
- **Chunk**: streaming world segment generated by `world/chunk_generator.gd`.
- **Hold interaction**: E/F timed interaction pattern using `hold_timer` and `interact_hold`.
- **Ghost placement**: temporary non-colliding placement visualization with material override.
