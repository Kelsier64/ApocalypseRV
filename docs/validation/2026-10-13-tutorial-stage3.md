# 教學基地階段三：第 2–6 關資源流程

2026-10-13 階段三實作與自動驗證紀錄。階段一、二已由使用者驗收；階段三的完整新局手動驗收尚待進行。基地幾何維持 40 × 416 m、九區長度 80、40、40、48、40、40、40、40、48 m；本階段未調整場地或替換 RV 原有設備。

## 完成內容

`TutorialWorkshop` 接在原 `TutorialController` 下，管理第二至第六關的指定供應品、持久 ID 及成功交易事件；控制器仍持有入口快照、重試和解鎖。終端頁提供各關條件；Esc 的 Restart Stage 從該關入口恢復，不覆寫手動檢查點。Checkpoint 外層維持 v5、StartRun 維持 v1，教學子狀態升為 v2、workshop 狀態為 v1。舊 v1 教學狀態會一次補上新版供應品與相同指定 ID，不重置既有完成進度；原入口只追加相同供應品及其版本化參考。

| 關卡 | 完成條件及指定資源 |
|---|---|
| 2 電池 | 把指定備用電池裝進原 RV 的原插槽並恢復供電；只把原電池裝回不計。準備保底的電量不計。 |
| 3 控制台 | 實際查看 rvctl Overview、Energy、Equipment，並成功關閉再開啟目前可用的 Cabin Strip。 |
| 4 放置 | 將新訓練分解機與工作台固定到原 RV，取消一次預覽，再將其中一台拆下重裝。兩台都須有供電且可用；RV 預設站台不計。 |
| 5 回收 | 把 Training Scrap A、Training Scrap B 和油桶投入指定新訓練分解機；必須實際入庫 8 Metal、10 Fuel，排隊或供應品被保底補充不計。 |
| 6 製造 | 在指定工作台佇列汽油配方，實際產出並拾取帶指定持久 ID 的汽油罐；只排入佇列不計。 |

供應品位置（基地局部座標）：備用電池 `(-8, 0.35, -306)`；訓練分解機 `(8, 0.03, -224)`；訓練工作台 `(-8, 0.03, -224)`；兩件廢料 `(8, 0.18, -178)` 與 `(9, 0.18, -178)`；油桶 `(8.5, 0.55, -174)`。新物品以 RV ID 加 `:training:*` 的穩定 ID 保存，依一般動態 Item 擁有權運作。實際底板射線驗證了 RV 後部工作台及分解機固定位置；保留中央走道、進料與出料空間，不替換預裝設備或新增 HUD。

## 原生畫面觀察

以 computer-use／`@oai/sky` 在 Forward+、1280×720 的專用遊戲視窗查看第二區備用電池、第四區兩台設備、第五區廢料／油桶，確認接地及車道淨空；亦查看第二關終端條件並以 Esc 關閉，沒有教學 HUD 殘留。沿用現有物品模型，沒有新增建築網格。日誌：`.godot/tutorial-stage3/native-review.log`。檢查中發現備用電池初始標籤未更新，已同步到其實際電量。

這次使用固定相機審查，未手動完整遊玩六關；自動交易測試也使用受控位置與靜止車輛，首關輪驅另有真實物理測試。關閉審查工具仍出現前階段相同的 Jolt／ObjectDB 清理警告，沒有執行中腳本錯誤；操作手感及全套美術留待使用者驗收／階段六。

## 手動驗收入口

啟動正式主場景新局（F5），或開啟 `tests/tutorial_shelter_playground.tscn` 後按 F6，依英文終端 Conditions／Steps／Controls 完成前六關。設備使用第四區的新訓練物品，搬運大型物品一次一件；空出車內中央走道與設備出料區。第 2–6 關均可從 Esc → Restart Stage 恢復完整入口與物資。完成第六關後應看到第一至第六道門開啟、第七道門及出口鎖定，終端顯示維修簡報尚未開放。
