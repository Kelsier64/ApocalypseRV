# Raker v015 小幅抬頭與轉向修正

2026-09-22，Blender 5.2.2 LTS、Godot 4.7.2 stable、Windows。

## 最終行為

- 保留 v014 的駝背、前彎頸部與內收手掌，只將待機／走／跑／狂奔頭部相對 v014 抬高 18°，仍保持略低頭。中立模型 2.18 m、面數、貼圖、碰撞契約不變。[側面](../../art_source/monster_refined_v015/walk_side.png)。
- 怪物原本立刻改變移動方向，身體朝向卻每幀只插值 10%，會側滑／倒跑，而且轉速隨物理更新率改變。Raker 現在按秒限速轉向（4.2 rad/s），平地站姿沿當前朝向前進，急轉減速，目標在身後時先轉身。
- 目標位於身後 150° 以外時鎖定左右回頭方向，轉至 100° 以內再解除，避免後方目標左右晃動造成突然翻向。蹲姿／車頂支撐／攀爬仍沿用既有共用控制器。
- playground 定速模式現在保留 A/D 轉向，F10 提供輪驅 S 型轉彎回放（36 km/h 目標）。命令加 `-- --turns` 可直接啟動。原有 F2 定速、F4 鏡頭、F6 重生、F8 預覽仍可使用。

- [轉向回歸](../../tests/test_raker_turning.gd) 在修正前實際失敗：90° 側向移動、180° 倒跑、不同更新率轉向不一致；證據 `.godot/test-logs/raker-turning-before.log`。
- 修正後通過：90°／180°、後方目標左右抖動、30／120 Hz 相同轉向量、S 型追逐朝向、模型／膠囊 scale 保持。Playground 回歸也驗證定速時 A/D 使正式輪驅車輛實際改變朝向。
