# v14 地形與植被細化

2026-10-20，Godot 4.7.2，分支 `codex/terrain-overhaul`。本階段完成後停止，等待使用者檢查實際渲染；不推送、不自動進入行車與長途驗收。

## 實作與相容性

- 正式新局改為 v14，舊 v2–v13 使用原生成分支。v14 的道路、地貌順序、河道計畫及既有基底噪音保留 v13 seed 域；道路中心線、寬度、坡度公式不變。新增 `terrain_relief_v14`、`flora_v14_trees` 與 `flora_v14_ground` 域，不消耗道路 RNG。
- 六類地貌增加世界座標侵蝕噪音，水平位移限制 ±12 m、局部侵蝕高度限制 ±4 m，保留原高度量級；區域末段 360 m 共用 `appearance_at` 的相鄰種類／混合比例。近地、遠側、horizon 材質與植被共用這份取樣。
- v14 獨立 shader 依坡度、岩石權重及濕度混合地表，岩壁使用三向世界投影。舊 shader 保留。河床、水位、岸線與近岸剖面公式未改，外側回接新地形。
- 新增兩種原生闊葉樹及草叢、蘆葦、小碎石、低灌木。植被按群落噪音與地貌機率配置；樹木排除大於 40° 坡面、水、路肩、橋墩所在道路帶及 POI 通道。候選點先量化為實際 Node3D 座標再查地形。保留 MultiMesh 分格裁剪、樹幹碰撞、穩定 ID、倒塌與 tombstone；闊葉樹葉材質用明確標記接入原 TreeFall。
- 沿用 v13 橋模型，跨度與基礎重新查詢 v14 地形。Checkpoint 外層仍為 v5；允許生成14，拒絕未來15，教學重試入口須保持同一版本。

## 固定鏡頭與區塊耗時

同機、同 seed／路段／相機／光照。每地貌建構四帶，暖機35幀後記錄40幀中位 render CPU／GPU。表格為 v13 → v14，單位 ms；不是整個遊戲 frame time。

|---|---|---|---|
| 草原 | 0.567→0.240 / 0.686→0.247 | 1.895→0.719 / 2.016→0.603 | 1552→1551 |
| 懸崖 | 0.763→0.386 / 0.618→0.410 | 2.296→1.300 / 2.467→1.932 | 1604→1329 |
| 濕地 | 0.646→0.435 / 0.725→0.372 | 2.304→1.167 / 2.516→0.945 | 1624→1509 |
| 山脊 | 0.485→0.200 / 0.484→0.171 | 1.525→0.700 / 1.571→0.644 | 1573→1248 |
| 峽谷 | 0.772→0.454 / 1.033→0.563 | 1.452→0.704 / 1.020→0.615 | 1716→1445 |
| 盆地 | 0.844→0.591 / 0.856→0.605 | 2.294→1.015 / 2.476→0.876 | 1646→1731 |

上表建構只包含地形、道路、水／橋及森林。單地貌最重值最大增幅為盆地5.2%，全24帶最大值1716→1731（+0.9%）。短樣本盆地 CPU 曾出現+15.3%，因此兩版本另以120幀暖機／120幀採樣重測：俯視 CPU 0.915→0.641、GPU1.751→1.014；路面 CPU0.891→0.616、GPU2.978→0.902，未重現超標。延長測量中四帶最重建構1720→1806（+5.0%）。

再用正式 `ChunkGenerator.generate` 即時流程量測帶 `[0,9,20,33,45,57,69]`，包含起始建築、路側靜物、探索裝飾、地形／橋／森林與導航來源／烘焙發布，排除動態角色。七帶最重建構3031→3018 ms（−0.5%），最慢導航就緒3914→3971 ms（+1.5%）。同地貌最大非起始帶增幅為盆地2751→3018（+9.7%）；起始帶冷建構1335→1620（+21.4%），仍遠低於最重帶，但此單帶冷啟動成本保留為後續追蹤項目。這是有限樣本的成本對照，未宣稱完整串流、幀尖峰或長途驗收。
