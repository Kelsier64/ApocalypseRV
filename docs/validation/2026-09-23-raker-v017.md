# Raker v017：限角增量與貼臉咬擊

2026-09-22 至 09-23，Godot 4.7.2 stable、Blender 5.2.2 LTS、Windows。

## 改動

- 上抬上限由 20° 改成站立 30°、蹲姿 40°；下壓 25°、左右各 90° 不變。站起當幀套用 30° 上限，追視分攤及 180°/s 不變。
- 咬擊 0.08–0.32 秒前探，0.40–0.65 秒收回；三節脊椎各最多偏轉 55°，用旋轉解算嘴部到玩家臉前位置。root／骨長不變。
- 抓握雙肩保持原接觸點，咬合時玩家頭部最多被拉近 28 cm；9 cm 半徑球體掃掠限制位移，角色碰撞體與座位不移動。取消、死亡和正常放開均恢復相機原位置。
- 咬合前短促 5° 俯仰／3° 側傾，傷害幀觸發 0.22 秒暗紅衝擊。沿用 2 秒掙扎、80% 判定、50 HP／致命傷害及既有死亡流程，沒有新增肢解系統。
- v017 增加唇緣、18 顆污黃牙齒、舌面與口腔材質整理；2.18 m、46 變形骨骼、41 段動畫保持。8,847 頂點／17,556 三角面／6 材質。

## 驗證

11 組 `test_raker*.gd` 與主場景啟動全部 PASS；最後牙齒法線修正後再次匯入並重跑資產與貼臉測試。`test_raker_neck` 驗證 30／40° 及站起上限；`test_raker_bite_pose` 驗證三姿態骨長／root 固定、身體不瞬移、真實 playground 地面／車內／移動駕駛，及前拉遇牆停止、解除復位、衝擊閃光清除。

真實場景測得嘴部距相機約 10–13 cm（浮點及物理時序略有差異）。已有追逐、奔跑、轉向、登車、破門／破頂、抓取結算、駕駛與 playground 回歸通過。日誌 `.godot/test-logs/`；本輪沒有重跑全專案其他領域。

加速測試退出曾出現 WAV playback 清理警告；測試結束前停用场景處理並停止音訊後，最終 verbose 重驗乾淨退出。正式 GLB SHA256：`4CF164889761F72FB070300DCEBB0F2A99AD50B86859B211C56B1FF7F923440D`。

Blender [掃描結果](../../art_source/monster_refined_v017/validation.json)：41 段／2,121 影格，身體自交與牙齒互穿均無檢出。刻意嵌入皮膚的唇緣／牙根交界不算錯誤；不代表任意運行時 IK、混合、翻車或怪物群均已窮舉驗收。
