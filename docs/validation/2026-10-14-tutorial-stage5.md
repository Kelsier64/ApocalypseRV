# 教學基地階段五：加油、啟程與說明書

日期：2026-10-14。階段五功能、選取自動驗證及原生固定鏡頭檢視完成；階段四、五合併人工驗收仍待進行。使用者已授權階段四、五連續實作並合併一次驗收；階段六尚未開始。

## 完成內容

第八關要求把第六關指定工作台實際製造的汽油罐轉入原 RV，並取得回傳空罐；準備期燃油保底不算加油，滿油拒絕時不消耗汽油罐。第九關要求第七關側牆、原引擎及指定備胎目前均可用，第八關加油已完成，維修蓋關閉，RV 停穩、手煞車、熄火後玩家離座按啟程按鈕。只有按鈕接受後時間、天氣和敵人才恢復；玩家與整台 RV 必須離開出口，出口受阻會重開，清空後才封門。正式啟程後不能重試或略過。

完成或略過會解鎖原持久 ID 終端上的同一本說明書。略過記錄 `Skipped`、清除重試入口並開啟內門，不造物品、不修車或補油，也不解除準備期；玩家仍要按啟程按鈕才開始旅程。終端可在背包、手持、RV 儲物、移動或丟棄、POI 保存資料等狀態保留說明書 v1 解鎖及結果，沒有 RV 建造權限。

說明書包含九課及按鍵參考，以英文顯示。搜尋會將多個詞都匹配到同一課才列出結果。階段五未更動基地幾何或階段六美術範圍。
