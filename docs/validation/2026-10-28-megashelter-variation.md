# 巨型避難所 v3：局部重製與隨機多樣性

2026-10-28。依使用者要求加深配色、改善模型細節並增加隨機外觀。延續[概念基準](../art/modular-megashelter/README.md)與[製作指南](../guides/megashelter-exteriors.md)。

- 保留三種主模板及既有尺寸抽樣；新增獨立建築 RNG，控制退台幅度／偏移、主柱寬度與間距、屋頂設備數量及種類。即使模板與尺寸相同，seed 也能改變結構配置。
- 三種暗色風格：灰綠、冷灰藍、灰橄欖。剝漆改為大片低對比磨耗，維持無窗、無黃色與廢棄狀態。
- 牆面增加補強鋼板、固定件、剝落鋼筋與變化百葉；設備型增加側立面豎井，並使用同一幾何包圍資料建立碰撞。
- 入口增加分層裝甲、鉸鏈座、固定件與三道閉鎖桿。屋頂重用既有模型，配置 1–3 台。
- 外殼內容版本 3、世界生成仍 v18。依既有政策，已造訪 v1／v2 外殼的舊存檔需重新開局。

驗證：Godot 4.7.2 匯入成功；`test_streaming_generation` PASS，約 32 秒。包含 32 seeds、上層完整支撐、固定尺寸多樣性、bounds／碰撞、同步與分幀模型一致、普通與巨人跨帶導航。日誌位於 gitignored `.godot/test-logs/20261028-124554-707-selected-40884/`。

實際檢視無霧畫面：seed 101 灰綠退台、109 冷灰藍中央塔、106 灰橄欖設備型板樓，以及入口／側牆近景。拍攝關閉距離霧和體積霧，使用相同檢查補光；正式世界環境未修改。截圖及暫用工具在 gitignored `.godot/art-work/megashelter/v3-*`。
