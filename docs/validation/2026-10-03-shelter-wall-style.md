# 避難所牆面真實感與風格修整

日期：2026-10-03。接續 [調暗與老化](2026-10-03-shelter-dark-walls.md)，依要求稍微提高真實感，同時遵守 GDD 的冷灰／土褐工業低模與低解析方向。

## 本輪調整

- 移除材質中鋪滿所有牆面的重複直條雨痕，改由既有窗台、管線和缺損位置的局部流痕呈現；流痕有不規則偏移、逐漸收窄和不同形狀，沒有硬切的矩形邊。
- 降低高頻顆粒對比與凹凸幅度，按畫面中公尺／像素比例淡出細節，模板縫與孔洞使用螢幕導數柔化。保留低反射灰褐色和上一輪工作燈亮度。
- 裂縫寬度沿路徑逐漸收細。剝落輪廓依位置確定性變化，薄邊使用實際面法線；露骨材區域有較粗的材質層次。維持簡單稜面與九個材質批次網格。
- 修改範圍為起始避難所獨立材質、離線製作來源及其外觀輸出。碰撞、導航、互動、物資與保存資料未修改。未使用子代理，沒有新增模型 request 或生成圖片。
