## 完成內容

- 完成設備、回收、製造、修牆換胎與加油後，原 RV 由駕駛座控制、發動、釋放手煞車並朝出口行進，即觸發提前感應開門。步行、靜止車輛或未完成準備不觸發；新版仍沒有手動啟程按鈕。
- 門開啟期間保持 preparing，時間、天氣與敵人停止。玩家及整車碰撞（包含突出車體的固定設備）完全離場，而且設備／修復／燃油仍可用、維修蓋及坡板收妥後，才開始正式遊戲。門口受阻重開，清空後永久封閉。
- 原終端切換為搜尋說明書，保留持久 ID、所有權、Item v2 開機及內部電量。涵蓋現場、固定、背包、手持呈現、RV 庫存、休眠及 POI 紀錄；略過顯示 Skipped，不捏造開機或教學交易，也不發放物資或燃油。未開機的原固定座在略過後亦可取走並閱讀說明書。
- Esc 提供 Restart Stage／Skip Tutorial，終端遺失仍可使用。接待室及第二室六個步驟各持有完整入口快照；現況與入口分別驗證 ID／所有權，禁止快照遞迴。重試使用隔離世界載入後替換，不覆寫手動存檔，失敗保留當前世界。坐在駕駛座時隱藏不能執行的重試／略過，離座後可使用。
- Checkpoint 外層 v5、StartRun v1 不變；兩室課程升為 v3，接受 v1/v2。保存感應門已開但尚未離場的狀態，以及完成／略過與原終端說明書。v2 不重新破壞或發料；v11 九關與 v7–v10 場址沿用原契約。
- F6 兩室測試場景亦可使用 F6／F9 保存與載入，載入目標仍是正式主世界；不把檢視相機或其他測試場景加入保存目錄。
- 教學條件與按鍵仍只在開啟終端時顯示，沒有新增教學 HUD。終端最後一步與搜尋說明書已更新自動出發說明。

## 驗收入口

開啟 [orientation_playground.tscn](../../tests/orientation_playground.tscn) 按 F6，或：

```powershell
godot --path . --log-file .godot/orientation-stage3-acceptance.log res://tests/orientation_playground.tscn
```

1. 沿終端完成第一室與第二室流程。最後一頁應引導收妥維修蓋／坡板、上車及直行，沒有啟程按鈕。
2. 向出口開車：前方大門自動開啟，尚在基地內時仍保持教學安全期；整台車及玩家離場後進入正式遊戲，出口隨後封閉。
3. 離座，選中原終端按 T，應直接開啟可搜尋 Manual 並顯示 Completed；保存／載入後仍保持說明書及封門狀態。
4. 另開新局，在任一工作坊步驟操作一部分後關閉介面、離座停妥，Esc → Restart Stage：應恢復該步入口，包含已消耗物品與材料，而不覆寫既有手動存檔。也可先保存／載入，再重試。
5. 另開新局，使用 Esc → Skip Tutorial：原終端顯示 Skipped 說明書、內門開啟；物資及燃油不增加。車輛仍須具備實際燃油、供電並收妥維修蓋／坡板，才能感應出發。
6. 大門已開但車輛未離場時，停妥、熄火、離座，待門停止後保存／載入：門應保持開啟，安全期仍有效，可繼續出發。

## 限制與保留

本輪是原生物理與介面資料的自動驗證，會控制玩家站位、瞄準及服務經過時間；沒有另做手動 WASD 完整遊玩或畫面驗收。兩室最終建築、燈具、海報、美術和完整套件留在階段四。

入口須等世界、門與操作穩定才建立；未具備入口時不顯示 Restart Stage，Skip 仍可使用。舊 v1/v2 存檔沒有歷史入口資料，載入後從可安全建立的當前邊界接續，不捏造已不存在的入口世界。一般手動保存仍要求離座並關閉操作介面；內部入口捕獲僅對有效的終端／rvctl 閱讀介面放寬 UI 限制，其餘驗證不變。

保留原有九區美術、專案設定、貼圖匯入、AGENTS／技能等未提交變更；測試目錄原有 `test_training_journey` 分類不納入本次提交。未推送或建立 PR。
