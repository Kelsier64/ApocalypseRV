# 第二室選做指南與全故障新局

## 行為與物資

- 第一室開機、原終端拆下與內門保持原判定。第二室沿用原 TUI，但隨時顯示全部選做參考及按鍵；可任意順序操作，成功交易獨立記錄。沒有新增教學 HUD。
- 原 RV 朝出口進入感應區即開門，不檢查教學紀錄、引擎、電池、燃油、牆、輪胎、屋頂、機器或維修蓋。原生故障、燃油與坡板仍透過一般車輛系統影響駕駛。玩家及完整車輛離場才恢復正式遊戲，即使清單未完成仍解鎖原終端說明書；受阻重開與永久封門保留。
- 新局保留兩片側牆各損 60、左前胎爆胎，新增原引擎 0／450 耐久、已安裝電池 0 電量、中段 `roof_1` 完全毀壞。中段原型是艙口屋頂，原生重建維持其類型，保留固定梯子所需空間。
- 第二室提供 8 件廢料、2 個油桶、滿電備用電池、2 包引擎維修包、健康備胎及兩台可搬運設備。新增架面、立柱與碰撞，分屬 POI Visuals／Collision；中央 8 m 車道保持淨空。所有物資使用原 Item 流程與固定 ID。
- 回收全部廢料／油桶保證 28 金屬、20 原油材料；一罐汽油花 2 金屬＋5 原油、兩片牆共 4 金屬、屋頂重建 6 金屬，剩 16 金屬。每包引擎維修包恢復 150，一包即可使故障引擎恢復運轉；第二包可改善耐久。取消 v12 電池保底，空電池不自動充電。
- 課程升 v4、工作坊子狀態升 v2，Checkpoint 外層 v5 不變。已配置的 v1 工作坊保留原 13 個目標與現有車況，只升級狀態；不補發新增物資或重施故障。舊 v3 入口快照同步升級，來源資料不改寫。尚未配置的早期課程沿既有首次配置路徑處理。
- 任意順序操作／額外回收可能在建議步驟轉換時一併完成，復原點取該批操作結束後的安全世界；已有復原點不被後續同段操作覆蓋。第一室仍不把部分開機冒充原始入口。重試不改手動檔案，失敗保留當前世界。

## 原生觀察與驗收

以 Forward+ 遊戲視窗檢視東側四組廢料架及兩油桶、RV 中段頂部缺口，以及西側架上的 100／100 電池和兩個維修包；架腳接地、物資落在架面，中央動線清楚。最新日誌 `.godot/orientation-optional-native-final.log` 無腳本錯誤。只關閉本次檢視遊戲，沒有操作編輯器。檢視相機及生成場景放在忽略目錄並已清理。

1. 用 F6 啟動 [orientation_playground.tscn](../../tests/orientation_playground.tscn) 或正式主場景的新局。開機並取走終端，進第二室。
2. 選中終端按 T，應看到 `Workshop field guide / Optional references`，可直接查全部參考，不需逐項解鎖。
3. 確認原電池為空、引擎完全故障、中段屋頂缺損；兩側共有八件廢料、兩桶油、充電備用電池、兩包維修包及備胎。
4. 可只處理實際行車所需事項，保留牆／屋頂或其他清單未完成後向出口開車：門應感應開啟。完整車輛與玩家離場後，終端仍切為說明書。
5. 另可參考指南完成全部操作；重建中段時使用原艙口屋頂型態。中途停妥、離座、關閉介面後保存／載入或 Esc 重試，確認沒有重新損壞或補發。

自動測試會控制角色站位、瞄準與服務經過時間；本輪沒有手動 WASD 完整遊玩。既有存檔不重設故障，因此要檢查新增初始車況及物資須開新局。最終建築美術及完整套件仍留在第四階段。
