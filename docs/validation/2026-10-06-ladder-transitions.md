# 梯子接近與交接手感

日期：2026-10-06。Godot 4.7.2 / Windows / Jolt。

> 本紀錄的頂端跨出流程已被 [梯頂停止與 WASD 手動離梯](2026-10-06-ladder-manual-exit.md) 取代；接近範圍與慢速接梯仍保留。以下為當時結果。

## 問題與修正

原本下端可從攀爬線外 0.85 m、左右 0.65 m 進入，面向 dot 僅需 0.35；接梯立即在同一影格抬升並對齊，登頂也立即跨出 1.2 m。這會讓玩家尚未貼近就被拉走。

- 下端向外接近距離縮至 0.22 m、左右 0.25 m，面向 dot 至少 0.8；上端只接受實際落腳點前後 0.25 m。上下鍵同時按不觸發。
- `begin_ladder_climb()` 只驗證路徑及建立狀態，不立即移動或旋轉玩家。已在接近範圍時先接梯，避免正常行走先越過攀爬線再拉回。
- ENTRY／LANDING 以梯子局部路徑點逐步抬腳、對齊及跨出，每秒最多 1.4 m，沿途保留膠囊碰撞與車輛位移補償。放開對應 W/S 暫停，屋頂交接反向輸入可退回，Space 可脫離。
- 攀爬速度由 2.6 降至 1.6 m/s，動畫播放同步降速；登頂收手在跨出途中開始，完成後不重播。身體與第一人稱鏡頭補償以 0.6 m/s 漸進，接梯／跨出鬆鍵時不繼續吸近。
- 保留工作樹正在更新的左側車內梯與三片屋頂。測試場相機改從梯子實際位置取景，屋頂狀態支援各片耐久；梯子支撐被摧毀後相機不再引用消失的節點。
