# Raker v019：來源掌心外翻

日期：2026-09-23。本次從 Blender 來源檢查並修正，取代前次僅針對執行期抓握的判斷。

## 原因與修正

直接載入 v018 `.blend`，量測 wrist／middle／thumb 的實際位置：idle 的兩側拇指朝 Blender +Y（身後）約 0.955，掌心朝外約 0.959；walk／chase／sprint 相同。追溯來源 v014 `aim_bone('hand_'+side, ..., sign*80)` 的扭轉，方向相反。網格手指順序及左右手骨架本身未交換，是來源動畫朝向錯誤。

v019 在 Blender 中建立私人 action 副本，使用實際拇指、指根方向建立手掌座標，重新烘焙六種步態、落地／受傷／死亡及其低姿態版本、18 段抓咬（共 30 段修改）。自然垂手時拇指朝前、掌心向內；抓握時拇指向頸部、掌心向下、手指前伸後向下彎。前臂從 bind pose 量測旋轉，避免以已錯誤的旧手腕姿態累加扭轉。攀爬及結構攻击片段保留。

保留 v018 網格、口腔、材質、身高 2.18 m、9,129 來源頂點、18,182 三角面、46 骨、41 段固定 root 動畫。重新匯出並替換正式 `assets/models/raker/raker.glb`，未新增遊戲內補轉手掌的程式。

## 證據與本次驗證

- Blender 前後固定相機近照：拇指金色僅用於诊斷渲染，不寫入模型。可以直接看到拇指從後方移到前方；正面圖看到掌面轉向身體內側。
- 全 41 段逐影格掃描：身體非相鄰面穿插 0 幀、牙齒穿插 0 幀、root 平移 0；嘴縫／口腔刻意接觸區排除方式與 v018 相同。此掃描不能取代所有遊戲中接觸 IK 的視覺檢查。
- 新增 `test_raker_source_hands.gd`：關閉 SkeletonModifier3D，以匯入來源動畫檢查六種步態及三種抓握，每段九個時間點、左右手分開檢查。舊 GLB 可重現 thumb FORWARD／palm INWARD 失敗；新 GLB 全部通過。
- `scripts/test.ps1 -TestFilter 'test_raker*.gd'`：匯入、14 組怪物測試及主場景啟動全部 PASS。
- `test_main_world_monsters.gd`：正式世界生成 2 個有材質、2.18 m 的 Raker，無舊怪物混入，PASS。
- 另開 Blender v019 來源檔，視窗列表確認檔名及路徑；原有未儲存 v017 視窗保留。原生 UI 存取授權逾時，未對 Blender 視窗送出編輯操作；來源檢查、烘焙、渲染與匯出均由 Blender background Python API 完成。
