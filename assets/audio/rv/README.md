將 Freesound 的公開試聽檔 轉成 44.1 kHz、16-bit 單聲道 WAV。將輸入依來源順序存為 `door.wav`、`gear_select.wav`、`vw_t5_road.wav` 和 `start_stop.wav`，放在忽略的工作資料夾，再執行下方指令。腳本需要 NumPy。

操作回饋、撞擊與接觸迴圈由 `make_rv_cues.py` 剪出，輸入依 Freesound 編號解碼並命名為：`handbrake_a.wav` 629323、`handbrake_b.wav` 200974、`switch_a.wav` 348225、`switch_b.wav` 788643、`hood_open.wav` 86233、`boot_close.wav` 136535、`ramp.wav` 455738、`ratchet_slow.wav` 591528、`ratchet4.wav` 333613、`bolt_clunk.wav` 391794、`wrench_a.wav` 551497、`wrench_b.wav` 616628、`thud.wav` 96137、`thump_bang.wav` 540847、`puncture_a.wav` 243375、`tree_trunk.wav` 550918、`collide_fast.wav` 332056、`collide.wav` 332058、`clank_crash.wav` 151624、`metal_impact.wav` 726486、`crash.wav` 237375、`crash_glass.wav` 592388、`squeal_4.wav` 71739、`sheet_scrape.wav` 646698。

```powershell
python art_source/audio/rv/make_pilot_wavs.py .godot/audio-source assets/audio/rv
python art_source/audio/rv/make_road_wind.py .godot/audio-source assets/audio/rv

```

直六引擎的定轉錄製順序見[取樣腳本](../../../art_source/audio/rv/make_bus_engine.py)。每點維持 4.8 秒，將 44.1 kHz 單聲道 PCM16 小端序原始輸出交給 `make_bus_engine.py <render.raw> assets/audio/rv/bus_i6.wav`。匯入時使用未壓縮 PCM，保留樣本邊界。腳本需要 NumPy 與 SciPy。

超過 10 秒的迴圈暫時仍是 WAV：目前的工具鏈沒有 Vorbis 編碼器，Godot 匯入時會壓成 QOA。
