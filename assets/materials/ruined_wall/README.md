# Ruined concrete aggregate texture

Created 2026-10-03. `aggregate_albedo.png` is an AI-generated base-color texture created with the built-in imagegen tool, not a photograph or a calibrated scan. The exact prompt is preserved in [the authoring folder](../../../art_source/ruined_wall/prompt.md). No runtime references depend on Codex's generated-images directory.

The production shelter's [formed concrete material](../../../world/starting_shelter/materials/formed_concrete.tres) reuses this texture for authored recessed damage, with mipmapped sampling and reduced contrast. Fine bump is an artistic derivative of image intensity, not a measured normal/height scan. The original cement texture's provenance remains in [the POI kit README](../poi_kit/README.md).

This texture was originally made for an independent wall study. Its high-density mesh, through-hole, rebar and study shader are not included in this production integration.
