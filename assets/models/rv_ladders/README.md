# WAYFARER 可搬移梯子

本專案原創 GLB，由 [build_rv_ladders.py](../../../scripts/build_rv_ladders.py) 使用 Python 標準庫重建；沒有外部素材或建模需求單。

| 模型 | 登高 | 三角形 | 用途 |
|---|---|---|---|
| side_door_ladder.glb | 1.30 m | 1,360 | 側門門檻；梯柱止於門扇下方 |
| roof_ladder.glb | 2.21 m | 1,952 | 車內地板到車頂，另有 0.37 m 握持端 |

單位公尺、Y 向上、原點在梯腳，+Z 為攀爬側，-Z 背面固定片共面貼牆；梯面與牆平行。短梯從 -Z 越過門檻，長梯從 +Z 離開牆面登頂。梯柱寬 0.86 m，登高與攀爬路徑由設備場景定義。深綠漆、奶油白端蓋、橘色辨識帶、金屬踏板與橡膠端套使用五個 PBR 材質，內嵌原創 128 × 128 磨損貼圖與近鄰 mipmap；ladder_wear.png 是來源的獨立副本，*_0.png 是 Godot 從 GLB 擷取的貼圖。

模型只含視覺，行為與碰撞由 [側門梯](../../../equipment/side_door_ladder.tscn)、[車內梯](../../../equipment/roof_ladder.tscn) 持有。模型不承擔存檔或設備登錄。
