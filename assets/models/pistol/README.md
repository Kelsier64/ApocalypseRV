# 手槍

2026-10-11 以 Blender MCP 原創製作的復古低多邊形半自動手槍；964 三角面，長 0.20 m，+Y 向上、-Z 槍口。Frame、Slide、Barrel、Magazine 分件，供 Godot 處理滑套／換彈表現。磨損為 GLB 內嵌的原創 128 px 貼圖；無外部素材或授權依賴。

正式包裝場景為 [pistol.tscn](../../../props/pistol.tscn)，碰撞、握持點與 Muzzle 留在 Godot。原始 Blender 工作副本及產製腳本保留於忽略目錄 `.godot/art-work/pistol/`。槍聲／空槍／換彈使用腳本合成原創 PCM。
