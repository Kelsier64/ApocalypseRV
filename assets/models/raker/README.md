# 裂爪 Raker

獨立的新怪物；目前遊戲使用 2026-10-26 B 方向灰橄欖粗糙材質與同日對稱頭臉細化，建立於 v021 左右手完整重建、v019 掌向、v018 口腔與 v012 加密模型，共 41 段動畫。待機／走路／奔跑／狂奔共用駝背、前彎頸部、收肘、拇指朝前與掌心朝內，四指朝掌心彎曲，切換步態保留腳步相位。新掌部、拇指根部、指縫與三節四指在 Blender 重新建模、綁定和製作 41 段張合動畫；保留掌心向內的方向。[整手重建歷史驗收](../../../docs/validation/2026-09-23-raker-v021.md)。

2026-10-26 B 材質跟進（現行）：以 Blender 原生三維程序色彩、表面起伏與粗糙度取代先前的平滑紅紫屍斑材質；不使用前兩張 ImageGen 色彩來源。灰橄欖／中性灰色塊、約 7–20 mm 的凹凸與肩頸／關節皺摺分開烘焙，加入局部 AO，避免只在底色畫明暗。此輪全部 3,282 項 accessor 的定義及資料、節點、mesh、蒙皮與 41 動畫均與 `4a12d42` 相同；無新增切線屬性。正式 GLB 與候選相同。Blender 同光照來源／烘焙圖平均 RGB 誤差 0.084/255，Godot 已核對正式匯入、底色、法線及 ORM 通道並輸出實際原姿勢渲染；未執行行為測試。眼部造型與 512² 貼圖沿用，口腔底色改為深灰綠。[材質製作與檢查說明](../../../art_source/raker_materials/README.md)。外觀待使用者驗收。

2026-10-26 較早外觀（材質已更換）：以屍斑色彩來源替換舊乾皮紋理，移除影像導出的密集皺褶法線。較平滑的表面搭配肩背、胸腹、膝肘與指端的大塊紫褐／灰藍色差；材質投影與局部臉形調整均沿 X 軸對稱。眼眶、臉頰與嘴邊僅做小幅頂點修整；原本內凹的眼部插片修成微凸曲面，另給 512² 專用眼睛色圖及 UV。動作、骨架、蒙皮、面索引與其餘 UV 不變。

2026-10-26 較早頭臉細化技術檢查（歷史結果）：相對該輪起點，56 節點、54 骨 skin、41 動畫與全部動畫取樣資料相同。3,282 個 accessor 中只有皮膚位置／法線與眼部位置／法線／UV 五項不同，其餘 3,277 項資料完全相同；皮膚位移上限約 4.96 mm，眼部凸面修正上限約 15.92 mm，法線均為有限單位向量，鏡射位移核對通過（來源本身有少量頂點取樣差異）。正式 GLB 與當時候選 SHA-256 相同。Godot 4.7.2 Forward+ 正式場景已輸出同光照全身／軀幹比較、頭部、背面與原抓握／咬擊姿勢；匯入、渲染日誌無錯誤；未重跑戰鬥／攀車／物理測試。

2026-10-25 幾何細化增加肋弓、鎖骨、肩胛、脊椎與前臂肌腱的淺浮雕，並烘焙乾皮皺褶、眼窩色差、疤痕、指甲角質及粗糙度（該輪乾皮材質現已更換）。保留原拓樸、節點、骨架、蒙皮與動畫資料；身體位置與法線局部調整，口腔、牙齒和手部幾何不變。原始模型保留於 [v021 GLB](../../../art_source/monster_refined_v021/raker_refined_v021.glb)。

2026-10-25 材質跟進（歷史版本）：以 ImageGen 乾皮紋理取代大塊程序斑駁，加入細微毛孔／皺褶、皮下色差與角質反光。這輪只替換材質及貼圖，全部幾何、UV、骨架與動畫資料相對 `4942b43` 完全不變。

2026-10-25 材質跟進驗證（歷史結果）：56 節點、skin、mesh、41 動畫，以及全部 3,282 個 accessor 的定義與資料均與當時細化後基準相同；正式 GLB 與當時材質候選逐位元相同。已在 Godot 4.7.2 Forward+ 檢查同光照前後比較、軀幹、背面、抓握及手腕／指甲近照，匯入及渲染日誌無錯誤；未重跑戰鬥／物理回歸。下方抓取測試結果屬同日更早的模型細化驗證。

## 可動頸部與抓咬

`raker_pose_modifier.gd` 在動畫後修正實際臉部朝向；yaw 左右 90°，pitch 站立上 30°／蹲姿上 40°／下 25°，180°/s，neck_01／neck_02／head 分攤 35／35／30%。角度以角色水平朝前為基準，補償蹲姿／攻擊動畫的低頭量；失去目標時淡回原姿勢，身後跨 ±180° 不反覆翻向。咬擊脊椎前探後再次校正臉向並限角，不會跟著軀幹朝下。

`grab_{stand,low,seat}_{reach,hold,bite,release,escape,miss}` 的來源片段為 0.6／1.0 循環／0.65／0.35／0.45／0.45 秒。Godot 將伸手加速到 0.36 秒，咬擊以約 1.73 倍速播放，把來源 0.38 秒的咬合對齊到實際 0.22 秒扣血；此時立即解除玩家硬控並切換收手。雙臂改抓頭部兩側，駕駛目標抬肘跨過椅背；兩段手臂都檢查遮擋，無可達路徑時抓空。

站立 reach／hold 只低頭看玩家，脊椎保持原動畫姿勢；加高後頸部下壓上限為 70°，bite 才前探且保留原咬合角度限制。雙掌朝頭部內側，手指向上包住腦後，咬擊時跟隨玩家頭部。抓取可達性採放大後世界骨長；抓駕駛時肘部向外張，物理檢查與視覺 IK 保持一致以避開車頂。來源骨架平移與 2.18 m 中立尺寸不變，行走／待機手勢仍使用原動畫。原有頸部／解除輸入驗收保存在 [歷次紀錄](../../../docs/validation/2026-09-23-raker-neck-hands-input.md)。

抓取固定抽 6–10 次新 Space 按壓，1 秒內滿額立即無傷脫困；期限到 ≥60% 扣 50，否則致命。玩家硬控保留重力、碰撞、RV 支撐；駕駛留座滑行。每次解除有 3 秒免抓，成功掙脫使怪物踉蹌 1 秒。8 傷害、死亡、移除、跨世界、座位或共同支撐失效都解除。攀爬中的玩家和結構沿用普通攻擊。

站立／低姿態／座位咬擊都以三節脊椎讓嘴部接近玩家臉頰。玩家頭部前拉 18 cm，駕駛另下拉 17 cm；球體掃掠防止穿牆，方向只在咬擊開始取一次，避免鏡頭與嘴部互追。抓住時抬頭看向怪物，角度固定直到咬完；怪物嘴部朝固定視線前 7.5 cm 前探。0.22 秒咬合保留暗紅衝擊，不施加向下或側傾頓挫；近距離 near 暫降到最多 1.2 cm，解除後復位。[固定視角與貼臉咬擊驗收](../../../docs/validation/2026-09-24-raker-fixed-grab-view.md)。
